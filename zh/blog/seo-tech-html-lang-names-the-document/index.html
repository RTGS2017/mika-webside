lang 属性应当标明文档的语言

html 元素上的 lang 属性标明这份文档的语言。把它设成你发布的正文的语言。在本站，英文 URL 使用 en，中文 URL 使用 zh-Hans。它不代替 hreflang。

短答

html 元素上的 lang 属性标明这份文档的语言。把它设成你发布的正文的语言。在本站，英文 URL 使用 en，中文 URL 使用 zh-Hans。它不代替 hreflang。

定义

语言元数据帮助读者和解析器知道这些词是哪种语言。如果属性写英文、正文是中文，文档就在自我矛盾。hreflang 关联两个 URL。lang 描述的是刚被获取的这一份文档。模板如果在每条语言路径上都印上 en，就是模板缺陷。不要为了“配合”属性而增加 /en/ 前缀。

页面上怎么出现

查看规范 URL 的源代码并读 html 标签。把它和 H1 以及第一段比较。再检查对照 URL。两份文档应标明各自的语言，并用 hreflang 互相指向，包括英文上的 x-default。

要检查什么

  • lang 与该 URL 的正文语言一致。
  • 英文和中文文档不共用一个 lang 值。
  • hreflang 仍然标出对照页。
  • 在模板里修复该属性，而不是只改一页。

一个结构示例

中文产品路径因为壳是复制的，所以 lang 仍是 en。修复是在该模板上设为 zh-Hans，并让英文文档保持 en。属性不会改写规格文字。不声称任何语言检测分数。

它不声称什么

正确的 lang 属性不保证排名或 AI 引用。Mika 不把语言标记当成市场份额。

Mika Visibility 把它归到哪里

lang 描述被获取的文档。hreflang 描述文档之间的关系。 Mika Visibility 把这项检查放在 SEO 健康轨道上，和可抓取性、状态码、页面基础放在一起。SEO 增长仍是另一个问题：哪些覆盖还没有写出来。GEO 仍是另一个问题：认真的读者能否在页面上找到可支撑的回答。没有混合总分。
