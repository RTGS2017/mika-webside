短答

分面导航通过对一组产品组合筛选器来生成许多 URL。

有些组合对应买家真正使用的购物路径。大多数组合是同一网格的单薄重排。跟着每个筛选链接走的爬虫，可能把获取花在近重复页上，更少看到重要文档。SEO 健康限制哪些组合被链接、可索引。它不假装每个组合都是一个主题。

定义

这里的抓取陷阱是按乘法增长的 URL 空间：颜色乘尺寸乘材质乘排序。内链应该强调你打算要的组合，其他组合可以在不被无尽链接的情况下到达，或按一条你能解释的规则不可索引。规则是模板决定。它不是名次。

抓取怎样遇到这条规则

只链接并为真正的文档做规范链接，阻止模板链接每一种组合。

当分面页没有自己的文字时，把每个分面 URL 的 canonical 指向未筛选的分类是诚实的。当分面页有你打算保留的独特引言时，这样做是错的。不要把这个选择藏在一个同时取消 URL 的纯脚本筛选器里。人仍然可以筛选。可抓取的链接应该与决定一致。

要检查什么

  • 链接每一种筛选组合的页脚或网格
  • 有独特文案的组合与单纯重排
  • 与该区分一致的 canonical 目标
  • 完全取消 URL 的纯脚本筛选
  • 一条分类 URL 作为样例

一个结构示例

阀门目录在分类页脚链接尺寸、合金和排序的每一种组合。可索引集合应该是分类本身和少数有真实文案的合金页。其他组合可以作为带有指向分类的 canonical 的筛选视图存在，页脚应停止把它们全部当作同等链接发出。

它不声称什么

控制分面不保证排名或引用。

Mika Visibility 把它归到哪里

Mika Visibility 把可抓取性放在 SEO 健康：robots 规则、状态码，以及爬虫能跟着走的路径。断开的路径和被挡住的模板是健康发现。缺主题不是。GEO 仍然依赖爬虫真正能到达的页面，但到得了并不等于替买家写好了答案。
