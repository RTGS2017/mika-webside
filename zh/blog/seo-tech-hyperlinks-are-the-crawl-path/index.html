短答

抓取路径是 HTML 里带 href 的锚点，指向一个返回文档的 URL。

图显示一份文档指向另一份。这就是全部机制。用带点击处理函数的 span 画出的菜单并不指向。在脚本里设置 location 的按钮，要等脚本运行才指向，而且可能不是对每个爬虫都指向。SEO 健康数的是锚点。它不把点击处理函数当成链接。

定义

href 应该是规范 URL，不是重定向链，也不是 javascript: URL。target 和样式不会创造路径。空的 href 或 href="#" 是通往无处的锚点。当仅有的引用是这些非路径时，孤立页的内部发现就会失败。

链接是路径，不是分数

对每一个你期望爬虫发现的文档，使用指向规范 URL 的真实锚点。

页脚、面包屑、正文和分页链接如果是锚点，就都是路径。从首页经枢纽到文档的一条路径就足以开始。更多锚点帮助人。它们不是某种“权重”计算，本页也不会编造。失效的锚点是链接腐烂发现。缺失的锚点是孤立页发现。

要检查什么

  • 原始 HTML 中有 href 属性
  • 目标是规范 URL
  • 没有用 javascript: 或空 href 做导航
  • 用锚点向外链接的枢纽
  • 在源代码中检查的一条枢纽 URL

一个结构示例

资源枢纽是一网格卡片。每张卡片是带 onclick 的 div。源代码里没有 href。修复是让每张卡片成为指向规范文章 URL 的锚点，并保留视觉设计。爬虫然后就能跟随枢纽。如果锚点存在，点击处理函数可以留下来作为渐进增强的装饰。

它不声称什么

真实的锚点不保证排名或引用。
