iframe 是另一次获取，不是父页面

短答

iframe 把另一份文档嵌进页面。获取父 URL 并不会自动把 iframe 的文字算进父页面的正文。如果你希望父页面被当成规格来索引，就把规格写进父页面的 HTML。

定义

嵌入适合放工具、地图或播放器。它们不适合藏起工作范围的唯一副本。iframe 有自己的 URL、自己的状态码，并且常常有自己的 robots 规则。如果该 URL 被阻止、是空的，或是第三方套话，父页面在截图里可以看起来完整，在获取结果里却是空的。SEO 健康从父响应实际包含的内容开始。

页面上怎么出现

获取父页面，在 HTML 里搜索规格句子。如果它只作为 iframe 的 src 出现，也要获取该 src。决定哪个 URL 拥有这个事实。当你需要抓取路径时，用普通链接指向它。不要指望框架继承父页面的规范地址。

要检查什么

  • 在父页面 HTML 里搜索规格。
  • 单独获取 iframe URL。
  • 不要把唯一的事实寄托在被 noindex 的框架上。
  • 给负责的 URL 一条普通内部链接。

一个结构示例

产品 URL 的 HTML 是一个标题加上一个 iframe，尺寸在 iframe 的来源里。该 iframe URL 被 noindex。修复是把尺寸写进产品 HTML，并把框架视为可选。然后复审父页面的获取。不背书任何嵌入供应商。

它不声称什么

把文字移出 iframe 不保证排名或 AI 引用。
