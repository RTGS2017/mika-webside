Web 字体改变的是字母的画法，不是词语

Web 字体是页面下载的字体，让浏览器能用那种设计来画同样的词语。

短答

Web 字体是页面下载的字体，让浏览器能用那种设计来画同样的词语。

图把 Web Fonts 这几个词画了三遍：衬线体、无衬线体和手写体。字母没有变。画法变了。当字体藏起文字、移动布局或加载失败时，SEO 健康把它当作页面基础。它不把一种字体当作排名信号，这三行也不是 Mika 的品牌系统。

定义

把词语放在 HTML 里。字体文件是呈现。因为字体难加载，就把产品名只画成图片里的路径，会把名称从一次获取能读到的文字里去掉。晚到的字体如果改变换行，就是布局偏移。预留空间，或接受一种接近的后备字体，让词语留在原地。如果系统字体已经能显示句子，就不要用一种装饰性手写体挡住整份文档。

页面基础里包括什么

把词语留在 HTML 里，并把 Web 字体当作这些词语的一种画法来加载。

在字体栈里写上后备字体。给字体文件一个大小和显示行为，不要让文字在整个加载过程中不可见。如果模板同时使用中文和拉丁字母，就检查这样一个页面，因为只覆盖其中一种的字体会替换另一种，并可能移动行。图中的三份样本是画法变化这个概念。它们不是三份必需的文件。

要检查什么

  • 产品名以文字存在
  • 字体栈里写了后备字体
  • 文件加载时文字没有一直不可见
  • 检查过晚到字体造成的布局移动
  • 在 HTML 源代码中阅读一条主视觉 URL

一个结构示例

主视觉把产品系列画成字母形状的 SVG，HTML 的 H1 是空的。修复是把系列名放进 H1，并用带系统后备的 Web 字体来画它。图中的手写样本没有被加进来。名称在源代码里可读。

它不声称什么

Web 字体不保证排名或引用。
