短答

HTML 视口是浏览器用来排版的页面区域，viewport meta 告诉移动浏览器使用设备宽度。

图是一个图形程序：四个窗格标着 Top、Front、Left 和 Perspective。这是这个词的一种真实用法，它不是 HTML head 里的标签。把两者混在一起，会写出碰不到文档的建议。SEO 健康要在人们用手机打开的页面上寻找这个 meta 元素。

定义

常见写法是一个名为 viewport 的 meta 元素，其 content 把宽度设为设备宽度。没有它时，许多手机会按一个很宽的虚拟尺寸排版再缩小，于是文字很小、点击落空。把宽度固定成比设备更窄或更宽的像素，会重现同样的问题。图里的建模窗格没有显示这个标签。它们只说明这个词为什么容易被用错。

页面基础里包括什么

在文档上放一个 viewport meta，并把宽度设为设备宽度。

不要再加第二个互相矛盾的 viewport meta。不要为了强迫版式而禁止缩放。只在 JavaScript 运行之后才注入该标签的模板，会让还没运行脚本的人第一次绘制就是错的。标签进入原始 HTML 之后，用窄宽度查看同一条 URL。三维窗格不是这项测试。

要检查什么

  • 原始 HTML 中有一个 viewport meta
  • 宽度设为设备宽度
  • 没有第二个互相冲突的 meta
  • 没有用禁止缩放来掩盖版式问题
  • 在窄宽度下打开一条产品 URL

一个结构示例

产品模板没有 viewport meta，在手机上规格表是一张被缩小的宽页面。修复是在共享 head 里加上设备宽度的 meta，并在窄窗口里检查一条产品 URL。建模截图留在来源页上，作为另一种视口的图片。它不是模板已经改变的证据。

它不声称什么

viewport meta 不保证排名或引用。
