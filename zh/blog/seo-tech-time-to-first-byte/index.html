短答

首字节时间是从发出请求到响应的第一个字节到达的等待。

图把重定向、缓存、DNS、连接以及响应体之前的服务器工作排在一起。沉重的主视觉图片不是这段等待。如果 HTML 文档本身就晚，后面的优化也会跟着晚开始。SEO 健康可以在样例 URL 上记下文档晚了。

定义

首字节是响应的属性，不是文案的属性。重定向链、缓慢的源站，或要等好几次后端调用才生成的文档，都可能把它推后。时序图是阶段图例。它不是对 Mika、某位客户或本营销站的测量。不要从公开图上抄一个数字，把它叫作这家公司的结果。

健康检查里怎么使用这个定义

说明晚的阶段是重定向、连接，还是服务器在生成 HTML。

CDN 可以缩短静态文件的连接建立，动态 HTML 文档仍可能在等源站。在页面允许被缓存时缓存 HTML，和缓存标志是不同的决定。SEO 健康不应把它们混在一起。在答案的一个字节能被发出之前，页面是否回答了买家这个 GEO 问题还排不上。

要检查什么

  • 文档之前的重定向链
  • HTML 是否动态且未缓存，而资源已被缓存
  • 首字节之前必须完成的后端调用
  • 连接建立与源站工作的区别
  • 晚到文档的一条样例 URL

一个结构示例

报价页从 http 重定向到 https，再到带尾斜杠的 URL，然后从三个服务拼出价格表。在任何产品文案存在之前，首字节就已经晚了。健康记录列出重定向链和文档，并附一条样例 URL。增加客户评价并不会去掉这些跳转。

它不声称什么

更快的首字节不保证排名或引用。

Mika Visibility 把它归到哪里

Mika Visibility 把它归在 SEO 健康：线上站点在技术上是否准备好被发现和理解。SEO 增长仍是关于覆盖和意图的另一个问题。GEO 健康与 GEO 增长保持各自的尺度。一条加载或响应性记录不会自动变成增长分数，也没有混合总分。
