短答

关键渲染路径是浏览器在画出第一块内容之前需要的那一组文件。

通常那是 HTML、为首屏定样式的 CSS，以及头部里没有 defer 或 async 的脚本。如果图片不是首次绘制所必需的，它们可以等待，但阻挡解析的脚本会拖住整条路径。SEO 健康列出模板路径上有什么。它不会把这份清单变成名次。

定义

渐进渲染图显示内容随着路径打通而出现。它是顺序的示意，不是本站的胶片。路径很长时，HTML 的首字节可以很快，首次绘制仍然很晚，因为绘制要等头部发现的阻挡文件。

渲染对爬虫意味着什么变化

列出一条样例 URL 头部里阻挡的样式表和脚本，把首屏不需要的东西移出这条路径。

defer 适合在 HTML 可读之后再增强页面的脚本。如果真有脚本是首次绘制所依赖的，defer 就不合适。大多数分析和聊天标签不属于那一类。审计应该点名标签和模板，而不是把“JavaScript”当成一种物质来责备。

要检查什么

  • 头部中阻挡解析的脚本
  • 首屏用不到的样式表
  • 在一条代表性 URL 上检查共享头部
  • 不包含主要内容的被推迟标签
  • 改完之后对同一 URL 的复查

一个结构示例

产品页头部在标题能绘制之前加载了全站样式表、活动样式表和三个阻挡解析的标签。只有全站样式表影响产品布局。健康改动是推迟这些标签，并在这个模板上停用活动样式表。如果头部是共享的，一条产品 URL 就足以看见这种模式。

它不声称什么

更短的关键路径不保证排名或引用。

Mika Visibility 把渲染当作 SEO 健康问题：当模板依赖 JavaScript 时，重要 HTML 能否在有脚本和无脚本两种情况下被获取并比较。这种比较不是 GEO 审计，也不是市场覆盖计划。发现要附在样例 URL 上。模板改完之后的再审计，用来确认修复。
