短答

图片格式是浏览器获取并绘制的文件类型。合适的类型是与画面匹配、并且真的能到达的那种。

这张图把格式沿着从采集和制作到交付的路径分组，一边是光栅类型，另一边是矢量类型。工具的标志出现在这张教学地图里。它们不是客户标志，也不是本站的合作方。SEO 健康不按图上坐着哪个品牌来给页面打分。它问的是 img 或 picture 元素是否指向一个能返回的文件，并且带有宽、高和 alt。

定义

照片可以是压缩的光栅图。扁平的图可以是 SVG，或一张仍然足够清晰的光栅图。模板点了名、服务器却不提供的格式，就是坏图，不管图上说哪种是现代的。提供一种你确定页面会加载的格式。picture 元素里的额外格式只有在主文件仍然可用时才是增强。不要因为某种格式在图上的格子看起来位于中心就选它。

页面基础里包括什么

提供模板所引用的格式，并带上尺寸和 alt。

检查图片 URL 的响应，而不是设计文件里有没有这种格式的名字。能加载的 JPEG 好过 404 的 WebP。元素上的宽高限制布局偏移。Alt 用页面的语言描述图片。这张图可以提醒团队照片和矢量是不同的问题。它不是一份必买清单。

要检查什么

  • 图片 URL 返回文件
  • 元素上设置了宽高
  • 页面语言的 alt
  • 如果同时还提供较新格式，后备文件是存在的
  • 检查过一次产品图片请求

一个结构示例

产品模板指向一个以 avif 结尾的文件，服务器上只有 jpeg。浏览器显示坏图。修复要么提供 avif，要么把 src 改成存在的 jpeg，并设置宽、高和 alt。没有把图上的任何工具标志加到页面上。

它不声称什么

图片格式不保证排名或引用。
