汽车本地化：每种语言保留同一个零件号

汽车本地化是指：你真正发布的每一种语言都出现同一个零件号、同一个工作范围和同一个安全限值。文笔流畅却改了扭矩数值的页面，是另一个零件，不是市场版本。

定义

供应商页面有用，是因为采购能把图纸对上正文里的一句话。这句话要写出零件号、条件和限值。翻译可以改语序，不可以另造一个限值、丢掉单位，或把零件号换成营销名称。英语在站点根目录，中文在 /zh/，hreflang 互相指向，x-default 放在英文 URL。这些信号只是指向页面，不能原谅规格对不上。

哪些字段必须说同一件事

比较流量之前，先比较六个字段：公司名、零件号、带单位的规格、应用、带条件的说法，以及该语言里买家问题是已回答、部分回答还是未覆盖。中文页把工作范围写短了，即使模板看起来完整，覆盖仍是部分回答。

页面上的问题

语言内的链接应留在读者正在使用的语言里。中文段落只指向英文图纸时，中文 URL 要靠另一种语言才能看到真正的限值。这同时是发现问题和可回答性问题。只出现在站点地图里的孤立译文，仍然难用。

随页面一起走的信号

限值的证据是句子旁边点名的图纸、数据表或标准。每种语言都需要一个打得开的证据链接。这里的引用就绪度，是读者能判断句子说的是哪个零件。它不是任何回答产品会引用该页的承诺。

在汽车零件页上，实体是零件号，不是宣传句。 Mika Visibility 要求每种已发布的语言保留同一套公司名、产品名、规格和应用，同时允许该市场的问题有真正的深度。英语在站点根目录，中文在 /zh/，不要增加 /en/ 前缀。hreflang 使用 en、zh-Hans，以及指向英文 URL 的 x-default。健康分数不会自动变成增长分数。

要检查什么

  • 在英文和中文 URL 上读出零件号和单位。
  • 确认安全限值连同条件一起留在译文里。
  • 检查线上规范 URL 之间的 hreflang 是否互相指向，x-default 在英文。
  • 从系列页沿一条同语言链接走到零件页。

一个结构示例

这是教学示例，不是客户故事。英文制动软管页在零件号 BH-240 旁边写了压力限值和温度范围。新语言版本保留标题，删掉了温度范围。买家问哪根软管对应某个发动机舱温度时，看到的是通顺的页面和错误的约束。修复是在该 URL 上补回范围，在同一语言路径链上图纸，然后复审。这个循环不是排名预测。
