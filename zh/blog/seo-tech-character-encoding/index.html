短答

字符编码是从字符到服务器发送、浏览器读取的字节之间的映射。

图中的纸带是一种旧的映射：用孔洞表示 Wikipedia 的字母，并标出 Carriage Return 和 Line Feed。它说明字母是一种编码，不是一份现代 HTML 文件的照片。SEO 健康关心的是你声明的编码就是你发送的编码，这样中文产品名和英文单位才不会变成替换字符。

定义

缺少声明时浏览器会猜测，猜测可能和文件不同。meta charset 说的是一件事，HTTP Content-Type 的 charset 说的是另一件事，这就是两张映射。HTTP 头在实践中常常优先，因此模板不应该依赖猜测。纸带上的控制标签提醒人们有些字节不是可见字母。它们不是要加到页面上的第二种字符集。

页面基础里包括什么

声明一种编码，并用同一种编码保存 HTML 文件。

整个响应最好只用一种字符集，在 HTTP 头里声明，并在文档开头的若干字节里用 meta charset 重复，这样保存下来的副本仍然知道。不要在构建步骤里把 UTF-8 文件转成旧编码，却留下原来的 meta。打开一个同时含有中文名和英文缩写的页面，在获取到的源代码里读这两段字符串。

要检查什么

  • HTTP 头和 meta 中是同一种字符集
  • 文件以该字符集保存
  • 源代码中的中文和拉丁文字都可读
  • 没有只转码不改声明的构建步骤
  • 获取并阅读一条双语 URL

一个结构示例

一份翻译后的规格书用旧编码保存，模板却仍声明 UTF-8。中文名变成一排替换符号，获取结果里也是这些符号。修复是按所声明的编码重新保存文件并重新获取。纸带只是编码的历史图片。它不是模板应该输出的文件。

它不声称什么

正确的编码不保证排名或引用。
