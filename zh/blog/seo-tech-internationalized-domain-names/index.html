短答

国际化域名是同一个主机，既可以显示为 Unicode，也可以写成 ASCII 形式。

截图圈出了一个使用希腊字母的地址，同一页上还用拉丁字母列出了其他主机。圆圈就是教训：可见的主机和编码后的主机是两种写法。SEO 健康希望链接、sitemap 和 canonical 元素里只有一种规范写法。它不把那张旧页面上的主机列表当作要复制的站点集合，也不把圆圈读成排名。

定义

ASCII 形式通常是 DNS 实际解析的 punycode 写法。浏览器可能显示 Unicode 形式。如果内链混用两者，一份文档就有两种 URL 字符串。把一种一跳重定向到另一种，并且 sitemap 里只放选定的形式。看起来像可信名称、实际用了不同字符的主机是另一个安全问题。这里的健康检查是你所拥有的主机是否一致，不是对浏览器如何画出字母的承诺。

这如何影响可索引的 URL

选定一种主机写法，并在规范 URL、sitemap 和内链中使用它。

把另一种写法重定向到选定的那种。不要把两者都列进去，好像它们是两个站点。Hreflang 是文档之间的语言信号。它不是用来合并 Unicode 主机和它的 punycode 孪生写法的工具。两种写法各获取一次，确认一种返回文档，另一种会重定向。

要检查什么

  • sitemap 和 canonical 中只有一种主机形式
  • 另一种形式一跳重定向
  • 内链使用选定的形式
  • 没有用 hreflang 代替重定向
  • 两种写法各获取一次

一个结构示例

营销站点在一些链接里印出公司名的汉字，在 sitemap 里却使用 punycode 主机。爬虫看见两个主机。修复是选定 punycode 主机作为规范，重定向另一种，并重新生成内链。图中圈出的希腊字母地址是别人的旧例子。它不是本站的主机，也不是一项结果。

它不声称什么

一种主机写法不保证排名或引用。
