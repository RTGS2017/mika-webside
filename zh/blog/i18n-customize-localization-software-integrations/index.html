定义

翻译软件可以存放字符串、状态和交接。搜索和买家不读那个数据库。他们读 URL。集成的终点必须是一份文档：每种语言一个规范 URL、一个标题，以及一次获取能返回的文字。如果唯一正确的句子只活在翻译工具里，网站仍然是部分回答。不要增加 /en/ 前缀。英语留在根目录，中文留在 /zh/。

短答

哪些字段必须说同一件事

对齐的是字段，不是感觉。公司名、产品名、规格、应用、说法和问题覆盖，应该能在接上的语言之间比较。用来放口号的自定义字段，不能代替工作范围。

页面上的问题

发布之后，获取两个 URL，并在 HTML 里读规格。工具里的预览不是抓取路径。译文页指向数据表的链接如果是断的，就会浪费你刚建好的路径。模板级的错误应在模板上修，而不是只改一个首屏。

随页面一起走的信号

hreflang 属于集成真正发布的那些 URL，包括自我引用，x-default 放在英文。站点地图可以在这些 URL 能返回预期文字之后列出它们。站点地图不会创造这段文字。

对买家来说，记录系统是页面，不是翻译连接器。 Mika Visibility 要求每种已发布的语言保留同一套公司名、产品名、规格和应用，同时允许该市场的问题有真正的深度。英语在站点根目录，中文在 /zh/，不要增加 /en/ 前缀。hreflang 使用 en、zh-Hans，以及指向英文 URL 的 x-default。健康分数不会自动变成增长分数。

要检查什么

  • 获取线上 URL，确认规格在 HTML 正文里。
  • 比较接入语言之间的产品名和单位。
  • 如果每种语言都丢掉同一个字段，就修模板。
  • 只给已经返回正文的 URL 加 hreflang。

它不声称什么

集成能用，不保证搜索排名或 AI 引用。Mika 不承诺任何连接器会把页面放进回答产品。

一个结构示例

这是教学示例，不是供应商评分。连接器把产品名和短标题送进另一种语言，压力等级却只留在源语言。线上页面看起来已经集成，却回答不了哪个等级适用。修复是把等级映射进发布的正文，并复审那一次获取。这里不给任何集成品牌排名。
