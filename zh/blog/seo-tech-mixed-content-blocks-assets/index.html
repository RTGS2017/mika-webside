短答

混合内容是 HTTPS 页面去请求 HTTP 资源。浏览器可能会阻止该资源。如果规格只存在于一张被阻止的图片里，页面就不再陈述这个事实。把资源改为 HTTPS，并把文字留在 HTML 里。

定义

文档能否被获取，和它的图片能否被获取，是相关但不同的检查。HTML 返回 200，仍可能引用不安全的图片、脚本或样式表。主动混合内容可以让脚本停掉。被动混合内容可以让配图消失。两件事都不会补上一句缺失的话。SEO 健康关心的是预期文字和证据文件能否被获取。它不把锁图标当成排名。

页面上怎么出现

用 HTTPS 打开规范 URL，列出仍然使用 http:// 的请求。更新模板，让生成的图片和脚本 URL 继承 HTTPS。不要把规格只留在图里。图注可以注明来源。说法属于正文。

要检查什么

  • 找出 HTTPS 页面引用的 HTTP 资源 URL。
  • 在模板里修好它们。
  • 在 HTML 正文里重复规格。
  • 重新获取页面和资源。

一个结构示例

数据表缩略图仍以 HTTP 请求，于是在线上 HTTPS 页面上配图消失，而 HTML 从未写明压力范围。修复是用 HTTPS 提供图片，并在旁边的正文里写上范围。不把任何安全徽章声称成商业结果。

它不声称什么

修好混合内容不保证排名或 AI 引用。Mika 不把 HTTPS 当成位置承诺。

Mika Visibility 把它归到哪里

被阻止的资源是该文件的获取失败，不是要追逐的排名信号。 Mika Visibility 把这项检查放在 SEO 健康轨道上，和可抓取性、状态码、页面基础放在一起。SEO 增长仍是另一个问题：哪些覆盖还没有写出来。GEO 仍是另一个问题：认真的读者能否在页面上找到可支撑的回答。没有混合总分。
