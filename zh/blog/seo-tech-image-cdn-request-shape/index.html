图片 CDN 仍然需要稳定且被说明的 URL

图片 CDN 根据参数生成变体，但每个有用的变体仍然需要一个稳定的 URL。

短答

图片 CDN 根据参数生成变体，但每个有用的变体仍然需要一个稳定的 URL。

流程图显示客户端请求尺寸和格式并收到该变体。当参数是模板有意选择的，这很有用。当每次浏览都加上随机破缓存参数或只差一个像素的宽度，就成了重复 URL 问题。SEO 健康看的是 URL 的模式，不是厂商的标志。

定义

CDN 主机名不是规范链接策略。如果同一张照片以几十种参数组合发布，站点就为一份资源准备了许多 URL。浏览器可能缓存不佳，爬虫也可能每次看到页面引用一个新 URL。健康记录列出参数模式和一条样例页面。它不声称 CDN 品牌会提升排名。

页面基础里包括什么

使用一小套有意的宽度和格式，不要在每次浏览时追加唯一参数。

HTML 仍然应该带有 alt 文字和预留盒子。CDN 不会写这些。每小时都变的签名 URL 对缓存和任何比较页面版本的系统都特别不友好。如果必须签名，引用它们的页面应被理解为有意不可缓存，审计应该写明这一点。

要检查什么

  • 一小段宽度阶梯，而不是每个像素一个 URL
  • 没有每次浏览都变的随机参数
  • HTML 里仍然有 alt 文字和预留盒子
  • 必须变化的签名 URL 已被标明
  • 一条图库 URL 作为样例

一个结构示例

产品图库按每位访客精确的 CSS 像素宽度向 CDN 要照片，于是 731、732 和 733 像素的文件都存在。模板应该请求一小段宽度阶梯。健康抽样是一条图库 URL 和参数模式，不是关于 CDN 的排名声称。

它不声称什么

图片 CDN 不保证排名或引用。
