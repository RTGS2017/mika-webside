短答

TLS 保护用来获取文档的连接。如果证书与主机名不符或已经过期，客户端可能永远读不到 HTML。有效的证书仍然不会写出规格。

定义

可达性包括名字解析、连接和响应正文。证书错误位于这条链的中段。SEO 健康可以报告线上 URL 无法被获取。不应把它和 SEO 增长混淆。增长问的是页面可读之后还缺什么覆盖。不要把挂锁当成产品说法的证据。

页面上怎么出现

打开规范 HTTPS URL，确认证书写的是该主机并且仍然有效。获取正文，确认主题在 HTML 里。在获取开始失败之前续期或重新签发。把 HTTP 重定向到同一个规范主机，而不是重定向到一个无关的证书名称。

要检查什么

  • 证书与规范主机名匹配。
  • 证书仍在有效期内。
  • HTTP 重定向到该 HTTPS URL。
  • 规格在正文里，不在挂锁上。

一个结构示例

证书覆盖 www，但规范主机是根域名，于是获取印刷出来的 URL 时名称检查失败。修复是为规范主机提供证书，并把另一个名字 301 到它。然后从 HTML 重新读规格。不声称任何信任奖项。

它不声称什么

有效证书不保证排名或 AI 引用。Mika 不出售信任徽章。

Mika Visibility 把它归到哪里

TLS 是获取的一个条件。页面基础仍然是响应里的文字。 Mika Visibility 把这项检查放在 SEO 健康轨道上，和可抓取性、状态码、页面基础放在一起。SEO 增长仍是另一个问题：哪些覆盖还没有写出来。GEO 仍是另一个问题：认真的读者能否在页面上找到可支撑的回答。没有混合总分。
