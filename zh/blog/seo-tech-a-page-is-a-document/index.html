短答

可索引的页面是一份文档：一个规范 URL、一个主题，以及一次获取能返回的文字。

单页应用里的一个状态可以看起来像页面，却仍然只是一个视图。如果该地址不返回这个主题的文字，它就还不是文档。SEO 健康从获取开始。设计仍然可以构建视图。应该被找到的视图需要文档。

定义

截图是浏览器里的一篇文章：一个标题、一个地址和一段正文。它提醒的是这个单位，不是要抄的线框，也不是本站声称属于自己的版式。这个单位有与 H1 匹配的标题、一种语言和一个主区域。它不必很长。单薄的文档和缺失的文档是不同的问题。不要为了让单位看起来完整而制造额外的 URL。

页面基础里包括什么

对每一个你希望被找到的 URL，让一次获取返回该主题的标题和主要文字。

把城市名换进同一段话的近重复文档，不是更多的架构单位。它们是一份被复制的文档。健康上的回应是保留真实文档并停止复制，这也是避免假装页面数量等于增长的方式。

要检查什么

  • 返回主题文字的一次获取
  • 标题和 H1 点名该主题
  • 仅有片段的视图不被当作文档
  • 没有为了膨胀数量而制造近重复
  • 获取并阅读一条预期的 URL

一个结构示例

每种合金的“页面”是一个 URL 为片段的标签。获取基础 URL 只返回第一种合金。修复要么给每种合金一个返回其文字的 URL，要么保留一份在 HTML 里包含所有合金的文档。标签可以留下来，作为在已经持有文字的文档内部移动的方式。

它不声称什么

拥有一份文档不保证排名或引用。
