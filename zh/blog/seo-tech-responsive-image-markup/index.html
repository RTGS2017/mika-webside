短答

响应式图片标记让浏览器选择适合即将绘制的位置的文件。

srcset 列出候选文件。sizes 告诉浏览器这个位置在布局里有多宽。艺术指导，也就是窄屏使用不同裁切，是用 picture 做的进一步选择。这些标记都不写 alt 文字，如果不同时设置宽高或比例，它们也不会预留盒子。

定义

把 2000 像素的产品照片送进 400 像素的卡片会浪费传输。把很小的文件送进全宽主视觉会显得糊。健康检查是标记是否匹配该模板的位置。艺术指导图展示的是裁切，那是布局选择。它不是性能分数。

页面基础里包括什么

让候选文件匹配真实位置，并在同一张图上保留 alt 文字和占位盒子。

每个断点都用同一张巨大文件的模板，是关于字节的健康记录。更换了裁切却丢掉 alt 属性的模板，是关于文字替代的健康记录。两者可以同时成立。SEO 健康把它们分开列出。图片内容，也就是照片描绘了什么，仍然要用页面语言写在 alt 里。

要检查什么

  • 匹配缩略图和主视觉位置的 srcset 候选
  • 描述布局位置的 sizes
  • 页面语言的 alt 文字仍然存在
  • 用宽高或比例预留盒子
  • 在两种宽度下检查的一条产品模板 URL

一个结构示例

产品模板在侧栏缩略图里使用相机原图，又把同一 URL 用作主视觉且没有更大的候选。缩略图浪费字节，主视觉又偏糊。标记应为侧栏提供小文件、为主视觉提供大文件，alt 文字点名产品，并设置宽高以免侧栏跳动。

它不声称什么

响应式候选图不保证排名或引用。这也不保证更富的图片结果。
