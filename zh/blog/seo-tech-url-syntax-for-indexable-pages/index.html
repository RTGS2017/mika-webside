短答

URL 由协议、主机、路径、可选的查询和可选的片段组成。

片段是给浏览器的，不会作为获取的一部分发给服务器。查询用来选择变体。路径通常是文档的身份。SEO 健康从这些字符串里选定一个作为规范 URL，并在链接、sitemap 和 canonical 元素里一致使用。

定义

语法图是标注辅助。它不说明一家公司选了哪种写法。选择是本地的：一个主机、一种协议、一种路径形式。其余的应该重定向或留在可索引集合之外。canonical 元素如果指向与 sitemap 不同的写法，就会重新打开重定向本来要关上的分裂。

这如何影响可索引的 URL

选定一种协议、一个主机和一种路径形式，不要让片段成为可索引身份。

http 与 https、www 与裸主机、有无尾斜杠，是把一个文档拼成两种写法的三种方式。健康规则是把不用的写法重定向到规范 URL，并且内部只引用那个 URL。#specs 这样的片段仍然可以给人用。它不应该是你列进 sitemap 的 URL。

要检查什么

  • 选定一种协议和一个主机作为规范
  • 尾斜杠一致，另一种形式有重定向
  • 片段不被用作 sitemap 身份
  • 内链使用选定的写法
  • 显示未用写法被重定向的一条样例 URL

一个结构示例

产品链接有时指向 http://www.example.com/pumps#curve，有时指向 https://example.com/pumps/。两个主机都有响应。规范选择是不带片段的 https 裸主机。重定向覆盖其他写法。sitemap 只列出选定的 URL。曲线章节可以仍然是页内标题。

它不声称什么

稳定的 URL 写法不保证排名或引用。
