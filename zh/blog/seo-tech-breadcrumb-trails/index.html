短答

面包屑路径是从当前页回到其所在栏目和首页的可见链接列表。

人用它向上移动。爬虫把它当作另一组内链，当主导航是 HTML 里不存在的脚本菜单时，这很要紧。路径应该匹配你打算的架构，而不是 URL 里的每个文件夹。这与面包屑标记是分开的，标记只是在你选择添加时重复这条路径。

定义

演示图显示一条简单路径。包含筛选器、会话参数或重复分类名的路径会教给人错误的地图。除当前页外，每个面包屑都应该是指向该层规范 URL 的锚点。当前页可以是纯文本，以免链接到自己。

结构如何承载发现

把路径渲染成指向规范栏目 URL 的 HTML 锚点，并把筛选器排除在面包屑之外。

如果只有在 JavaScript 运行之后才能看见路径，原始 HTML 就失去了这条路径。把路径放进服务器 HTML。路径与主分类法不一致是架构缺陷：同一站点有两张地图。选定一张。

要检查什么

  • 除当前页外面包屑都是锚点
  • 规范栏目 URL，而不是筛选 URL
  • 路径存在于原始 HTML
  • 一套分类法，而不是来自活动文件夹的第二张地图
  • 在源代码中检查的一条产品 URL

一个结构示例

一个属于“执行器”的产品显示路径首页 / 商店 / 促销 / 执行器，因为 URL 是从活动文件夹生成的。修复是在 HTML 里使用首页 / 产品 / 执行器 / 该产品，并带上锚点。活动可以是一条横幅。它不是架构里的父级。

它不声称什么

面包屑路径不保证排名或引用。
