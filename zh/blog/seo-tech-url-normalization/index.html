短答

URL 规范化为文档选定一种写法，并把其他写法当作重复。

主机上的字母大小写、尾斜杠、index.html 与目录、以及对不必编码的字符做百分号编码，是常见变体。SEO 健康选定规范写法，用一跳重定向其他写法，并只在链接、sitemap 和 canonical 元素里使用选定的写法。

定义

规范化与哪些参数属于身份不是同一个决定。那是查询字符串的说明。这里的主题是路径和主机。指向一个自身还会重定向的写法的 canonical 标签是一条链。让标签、sitemap 和重定向目标成为同一个 URL。

这如何影响可索引的 URL

把每一种替代写法一跳重定向到一个规范 URL，并且只链接到那个 URL。

选定斜杠策略并坚持。把 /pumps 和 /pumps/ 都当作规范会分裂信号。index.html 这类默认文档应该重定向到你选定的目录 URL，或者反过来，但不能两者都返回 200。样例是一对 URL 和它们的状态码。

要检查什么

  • 一个主机、一种协议和一种斜杠形式
  • index.html 或目录，不能两者都是 200
  • canonical、sitemap 和重定向点名同一个 URL
  • 内链已经使用该 URL
  • 带状态码的一对样例

一个结构示例

链接和 sitemap 使用 https://www.example.com/pumps/index.html，canonical 标签指向 https://example.com/pumps。两者都返回 200。修复是把 www 和 index.html 形式 301 到选定的 URL，更新链接和 sitemap，并让 canonical 标签点名同一个 URL。

它不声称什么

规范化不保证排名或引用。
