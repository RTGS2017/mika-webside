短答

关联数据是用标识符把事物连起来的一种方式。JSON-LD 是页面用来写下其中一些连接的一种语法。

图是许多圆点聚成簇、用线连起来的密集图画。它是一张大型公开图的图片，不是 Mika 的地图，也不是本文声称测量过的图。在产品页上，有用的形式更小：一块 JSON-LD，其名称、描述和标识符与可见文字一致。全球图画里的一条线不会制造这种一致。

定义

指向页面从未点名的事物的标识符是装饰。重复产品系列、制造商和文档 URL 的标识符，可以帮助解析器看见正文已经说出的内容。GEO 仍然依赖句子本身可理解。标记是技术性的 SEO 健康题目。它不会变成引用，簇图也不会给本站在那朵云里分配一个位置。

这种标记能做什么、不能做什么

编写重复可见事实的 JSON-LD，并只保留你能在正文里解释的标识符。

一种语法就够了。不要再加一块点名另一种产品的数据。不要因为别处有一张连得很密的图，就贴上一堆无关的标识符。把 JSON-LD 和 H1 放在一起读。如果人看不见这种联系，解析器的联系就不是证据。圆点图仍然是别人的数据的图片。

要检查什么

  • 与 H1 一致的 JSON-LD 名称
  • 正文真正解释了的标识符
  • 一种语法，没有互相冲突的第二块
  • 使用 canonical URL 作为文档的 URL
  • 一条产品页同时按 HTML 和 JSON-LD 来读

一个结构示例

阀门页的 JSON-LD 使用了另一个行业的标识符，以及一个页面上没有出现的名称。修复是删掉这块数据，并写一个对象，其名称是 H1，其 URL 是 canonical。没有从图里加任何一个圆点。正文仍然必须解释这个阀门。

它不声称什么

JSON-LD 不保证排名、富结果或引用。

Mika Visibility 把它归到哪里

Mika Visibility 把结构化数据当作技术性的 SEO 健康题目：标记应与可见事实一致，并且能被干净解析。它不出售富媒体结果的位置。GEO 仍然关心实体和证据在正文里是否可理解。重复口号的标记不会制造证据。
