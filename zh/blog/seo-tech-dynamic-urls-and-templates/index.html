短答

当一个地址持续返回爬虫可以获取的同一份文档时，动态 URL 就是可索引的。

图显示服务器在生成响应。这很普通，也没问题。有问题的是生成依赖会话 cookie、省略产品文字，或每次访问都改变文档身份。SEO 健康看的是被获取的 HTML，而不是有没有数据库参与。

定义

模板是修复的单位。产品模板上的缺陷会出现在每个产品 URL 上。抽样一条 URL 就足以看见它，修好模板就修好这一类。逐页改文案则不会。审计在发现的是模板时应该写“模板”。

结构如何承载发现

用干净的客户端获取模板中的一条 URL，并要求得到一份稳定的 HTML 文档。

选择真实记录的参数如果就是身份，可以留在 URL 里。选择用户的参数则不行。随 cookie 变化却没有 Vary 头的响应，或不该变化却变化的响应，会扰乱缓存和爬虫。先说明 URL 应该意味什么，再检查第二次获取是否一致。

要检查什么

  • 不带 cookie 的获取包含主要文字
  • 链接和 sitemap 中没有会话参数
  • 对规范 URL 的两次获取一致
  • 重复出现时把发现称为模板
  • 一条样例记录 URL

一个结构示例

不带 cookie 获取 /item?id=440 时返回阀门数据表，包括名称和 PDF 链接。/item?id=440&sid=随机值返回登录墙。健康规则是 id URL 才是文档，sid URL 永不被链接或放进 sitemap。模板是动态的，但仍然是一份文档。

它不声称什么

动态模板不保证排名或引用。
