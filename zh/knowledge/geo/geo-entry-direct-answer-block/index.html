定义

回答系统和买家都要确定这个 URL 回答哪个问题。口号确定不了。区块应在 HTML 正文里，而不只在图片或标题属性里。Mika 讲授的路径是问题、主题、意图、实体、证据，然后是直接回答。引用就绪度是这段文字的质量，不是位置。

短答

直接回答区块是页面靠前的一段短文字，用陌生人能够转述的句子写明主题、约束和事实。它是 GEO 健康的一个构件。它不承诺任何回答产品会引用它。

页面上怎么出现

为该 URL 选一个主要问题。写两三句话。用网站其他地方使用的方式点名产品。在同一段里写上限值。紧接着链接证据，锚文本点名文档。

区块可以很短。如果它仍然漏掉排除项，覆盖就是部分回答。补上排除项。不要再加一个形容词。同一个事实应出现在根目录的英文和 /zh/ 下的中文里。

Mika 把这称为直接回答。它不是保证出现的摘要。 Mika Visibility 里的 GEO 是生成式引擎优化，不是地理定位。四个构件是实体、直接回答、证据和一致的上下文。引用就绪度是页面可以被更少歧义地转述的质量，不是任何回答产品会引用它的承诺。

要检查什么

  • 该 URL 只有一个主要问题。
  • 第一段点名主题、约束和事实。
  • 这段话是 HTML 正文。
  • 两种语言出现同一个事实。

一个结构示例

教学问题是哪种产品适合低层混凝土浇筑。区块点名系列、层高约束和数据表。只说“为建造者而设计”的页面还没有区块。这个场景是说明，不是客户。
