短答

这里讨论的光学字符识别，是为了让读者或摘写系统能够确定事实是文本，还是只是一张扫描图。有用的页面会写明即使同时提供扫描件下载，也把数值写进 HTML。与这句话放在一起的证据是与扫描件一致的 HTML 表格。引用就绪度指的是，一个仔细的读者可以更少歧义地为这句话注明出处。它描述的是页面质量，不是任何回答产品一定会引用该页。

它如何出现在网站上

回答系统拿不到销售的私下说明。它们读到的是 HTML 里真实存在的句子、名称、表格和链接。如果正文始终没有说清事实是文本，还是只是一张扫描图，摘要就只好猜测你希望被复用的字段的转写。这种猜测是页面的失败，即使站点在技术上可以访问。

光学字符识别：是把像素转换成字符。它并不稳定，也不是一种发布策略。具体做法并不宏大：即使同时提供扫描件下载，也把数值写进 HTML。把这段话放在买家会落地的位置，而不是只放在口号或标题属性里。然后把它连到与扫描件一致的 HTML 表格，让主张和支撑彼此对得上。

不要依赖外部系统对你的证据做 OCR 并且做对。如果扫描件就是证据，页面仍应说明这是什么扫描件、哪些字段重要。没有转写的文件图片，对主张来说只是部分覆盖。

问题覆盖只有三种诚实状态：已回答、部分覆盖、未覆盖。页面提到了主题，却没有回答事实是文本，还是只是一张扫描图，最多算部分覆盖。整站从未提出这个问题，就是未覆盖。GEO 增长用来记下这个缺口。GEO 健康用来看现有页面能否支撑一个答案。两条刻度都不合成一个总分。

要检查什么

在正文里写出名称

用陌生人读得懂的句子写出名称。首屏应写明即使同时提供扫描件下载，也把数值写进 HTML。只写“解决方案”的标题并不能标识实体；藏在下载文件里、正文从未出现的型号，也不会进入没有读到那句话的摘要。

用一段话回答问题

要用白话回答的问题是：事实是文本，还是只是一张扫描图？这一小段应该可以单独被引用。如果这段话仍然留下你希望被复用的字段的转写，就把覆盖记为部分覆盖，补上缺少的限制、范围或排除项，而不是再加一个形容词。

把证据放在主张旁边

这一页的证据是与扫描件一致的 HTML 表格。用能说出目标内容的锚文本链接过去，并确认目标网址打开的就是那份文件。没有可打开支撑的主张，就算句子很有信心，也不具备引用就绪度。

两种语言保持同一事实

英文在站点根路径，中文在 /zh/ 下，公司名称、产品名称、规格和应用应保持一致。翻译可以改变语序，不应发明第二个光学字符识别或第二套运行范围。Hreflang 标明语言版本。它不猜测回答产品会偏好哪一种语言。

一个结构示例

没有 HTML 转写的扫描证书，会迫使每一个读者——人或自动系统——去猜字符。把你希望被引用的字段转写出来：名称、范围、日期。Mika 教学材料里的对照也是这一类：一页只有口号，另一页写明公司、产品系列、应用和限制，并在主张旁边放上规格书。这是示意，不是客户案例，也不是测量结果。
