短答

这里讨论的信息检索，是为了让读者或摘写系统能够确定所需事实是否写在系统取得到的页面上。有用的页面会写明把事实写成可索引网址上的普通句子，而不是只留在销售通话或上锁文件里。与这句话放在一起的证据是同一事实既出现在可见 HTML 中，也出现在页面所链的文件里。引用就绪度指的是，一个仔细的读者可以更少歧义地为这句话注明出处。它描述的是页面质量，不是任何回答产品一定会引用该页。

它如何出现在网站上

回答系统拿不到销售的私下说明。它们读到的是 HTML 里真实存在的句子、名称、表格和链接。如果正文始终没有说清所需事实是否写在系统取得到的页面上，摘要就只好猜测事实本身，因为它从未发布。这种猜测是页面的失败，即使站点在技术上可以访问。

信息检索：是去找一份包含所求事实的文件。系统取不回网站从未发布的句子。具体做法并不宏大：把事实写成可索引网址上的普通句子，而不是只留在销售通话或上锁文件里。把这段话放在买家会落地的位置，而不是只放在口号或标题属性里。然后把它连到同一事实既出现在可见 HTML 中，也出现在页面所链的文件里，让主张和支撑彼此对得上。

检索不是说服。页面是一份文件。文件里没有温度、范围或排除项，品牌用语再多也配不上。GEO 健康问的是现有页面能否支撑答案。GEO 增长问的是哪些问题仍然没有文件。把这些缺口和“模型会补上一句”的希望分开。

问题覆盖只有三种诚实状态：已回答、部分覆盖、未覆盖。页面提到了主题，却没有回答所需事实是否写在系统取得到的页面上，最多算部分覆盖。整站从未提出这个问题，就是未覆盖。GEO 增长用来记下这个缺口。GEO 健康用来看现有页面能否支撑一个答案。两条刻度都不合成一个总分。

要检查什么

在正文里写出名称

用陌生人读得懂的句子写出名称。首屏应写明把事实写成可索引网址上的普通句子，而不是只留在销售通话或上锁文件里。只写“解决方案”的标题并不能标识实体；藏在下载文件里、正文从未出现的型号，也不会进入没有读到那句话的摘要。

用一段话回答问题

要用白话回答的问题是：所需事实是否写在系统取得到的页面上？这一小段应该可以单独被引用。如果这段话仍然留下事实本身，因为它从未发布，就把覆盖记为部分覆盖，补上缺少的限制、范围或排除项，而不是再加一个形容词。

把证据放在主张旁边

这一页的证据是同一事实既出现在可见 HTML 中，也出现在页面所链的文件里。用能说出目标内容的锚文本链接过去，并确认目标网址打开的就是那份文件。没有可打开支撑的主张，就算句子很有信心，也不具备引用就绪度。

两种语言保持同一事实

英文在站点根路径，中文在 /zh/ 下，公司名称、产品名称、规格和应用应保持一致。翻译可以改变语序，不应发明第二个信息检索或第二套运行范围。Hreflang 标明语言版本。它不猜测回答产品会偏好哪一种语言。

一个结构示例

买家询问最高环境温度。如果这个数字只在私人表格里，检索就没有诚实的结果可返回。把数字和试验条件一起写在产品页上，检索才有文件。Mika 教学材料里的对照也是这一类：一页只有口号，另一页写明公司、产品系列、应用和限制，并在主张旁边放上规格书。这是示意，不是客户案例，也不是测量结果。

它不声称什么

把信息检索写清楚，会让仔细的读者更容易理解并参照这一页。Mika 不保证搜索排名，也不保证被任何 AI 产品引用。并不承诺会被 ChatGPT、Gemini、AI Overviews 或其他回答界面收录。没有解决事实本身，因为它从未发布，是站内要补的内容缺口，不是对谁会被引用的预测。
