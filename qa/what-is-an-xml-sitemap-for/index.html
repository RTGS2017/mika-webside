What is an XML sitemap for?

An XML sitemap is for declaring URL coverage and freshness, and it can still disagree with the index.

Definition

An XML sitemap lists URLs so coverage and freshness can be declared in one place. The list can still disagree with what is indexable, so a listed URL is not automatically an indexed URL.

Short answer

An XML sitemap declares URL coverage and freshness. It can still disagree with indexation, because a URL in the file may not be the indexable version.

What to check

  • Read the sitemap URL list
  • Note coverage and freshness
  • Compare the list with indexable URLs
  • Expect possible disagreement

What this does not claim

Listing a URL in an XML sitemap does not guarantee that the URL is indexable or positioned in search. Mika does not guarantee that coverage and freshness entries match the index.

A practical example

Suppose an XML sitemap lists a product URL and a freshness signal, while that URL is blocked or is not the canonical version. The sitemap has declared coverage and freshness, and it can still disagree with what is indexable.
