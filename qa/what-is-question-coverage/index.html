What is question coverage?

Question coverage shows which buyer questions a page answers, which it only mentions, and which no page covers.

Definition

Question coverage maps buyer questions to pages and marks them answered, partial, or uncovered. The map shows which questions already have a direct answer, which are only mentioned, and which no page addresses.

Short answer

Question coverage maps buyer questions to pages and marks each one answered, partial, or uncovered. It is a coverage map of questions, not a scoreboard of rankings.

What to check

  • Buyer questions are mapped
  • Answered questions are marked
  • Partial questions are marked
  • Uncovered questions are marked

What this does not claim

Question coverage does not guarantee that answered questions will be cited or ranked. Mika does not guarantee search rankings or AI answer citations because a question is marked answered, partial, or uncovered.

A practical example

A buyer question about low-rise concrete placement can be marked answered when the product page states the use case, the constraints, and the specifications. The same map can mark another question partial or uncovered when no page answers it directly.
