Which status codes matter for crawling?

Status codes matter on a crawl because a non-success response can stop the crawler from continuing.

Definition

Status codes matter because a non-success response can stop the crawl. Soft 404s are named in the open-source SEO crawler note, so a URL that looks present while failing as a soft 404 belongs in that same status review.

Short answer

Non-success responses matter because they can stop the crawl, and soft 404s are named in the open-source crawler note. Review status codes as signals about whether a crawler can continue, not as a ranking scoreboard.

What to check

  • Non-success can stop a crawl
  • Soft 404s are in the note
  • Status can block the path
  • Codes are crawl signals

What this does not claim

Correct status codes do not guarantee full crawl coverage or rankings. Mika does not guarantee search rankings or AI answer citations when non-success responses and soft 404s are fixed.

A practical example

A URL that returns a non-success response can stop the crawl at that address, so the status code matters to the path. A soft 404, which the open-source crawler note names, also matters because the URL may look available while not serving a real page.
