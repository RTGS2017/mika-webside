What is a website entity?

A website entity is a stable name and fact set, not a slogan that changes from page to page.

Definition

A website entity is a stable name and fact set for the company, products, places, or documents. The same facts should stay recognizable when that name appears, including on a product application or a document.

Short answer

A website entity is the stable names and facts for a company, product, application, place, or document. Readers should not have to reconcile a different fact set on every URL.

What to check

  • Use one stable company name
  • Keep product and document facts stable
  • Include places tied to those facts
  • Do not swap in a changing slogan

What this does not claim

A stable entity name and fact set does not guarantee that AI products will recognize or cite the company. Mika does not guarantee a position or a citation from entity clarity alone.

A practical example

Suppose the company name, the product name, and a document title stay the same on the English root page and the Chinese page under /zh/. That stable name and fact set is the website entity, rather than a slogan that changes from page to page.
