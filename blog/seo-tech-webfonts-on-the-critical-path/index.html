A Web Font on the Critical Path Blocks the First Text

Short answer

A font is on the critical path when the first text cannot paint until that file is known.

The path runs from HTML to the stylesheet that names the font, then to the font file. Every extra family inserted there delays the chain. SEO Health asks which face the first screen truly needs and which faces were added because a brand kit was pasted into the head.

Definition

Critical path is a loading idea, not a design critique. A distinctive display face can still be used below the fold or after the first paint if the first text has a readable fallback. The diagram shows the chain. It is not a measurement of Mika, of a customer, or of this marketing site.

What rendering changes for a crawler

Keep only the first-screen face on the chain from HTML to font file.

Subsetting a font to the characters the template uses makes the file smaller, which matters when that file is on the chain. Subsetting is not an excuse to block rendering on five families. Icon fonts that exist only to draw a few arrows are especially poor members of this path; an inline SVG for those arrows does not hold up the document.

What to check

  • Font families requested before first text
  • Icon fonts used for a handful of arrows
  • Faces used only on other templates but loaded globally
  • A sample product URL’s head markup
  • Fallback text that is not hidden

A practical example

A global stylesheet requests a text face, a condensed face, and an icon font before the product title can show. The title only needs the text face. The health change removes the other two from the head of the product template. The campaign layout that uses the condensed face can request it on its own pages.

What this does not claim

Shortening the font chain does not guarantee rankings or citations.
