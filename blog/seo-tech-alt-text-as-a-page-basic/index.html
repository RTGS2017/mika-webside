Alt Text States What the Image Depicts, in the Page’s Language

Alt text is the words that stand in for an image when the image is not seen.

Short answer

Alt text is the words that stand in for an image when the image is not seen.

An informative product photo needs a description of what it shows, in the language of the page. A decorative rule or spacer can use empty alt so it is not announced as content. The filename, “IMG_2044,” is neither. SEO Health treats missing alt on informative images as a page basic, and misleading alt as a worse defect because it states the wrong thing.

Definition

Alt is not a place to repeat a keyword list. A keyword list is not what the image depicts. The figure on this page shows text standing in for a picture, which is the idea. It is not a scoring rubric. The same image used in an English page and a Chinese page needs alt in that page’s language, not a copied English string on both.

What belongs in the page basics

Describe informative images in the page language, leave decorative images with empty alt, and never use the filename.

Width and height remain a separate basic so the image does not shift the layout. Alt does not reserve the box, and a reserved box does not describe the picture. A template that sets alt equal to the title attribute on every image will duplicate a bad title. Write the description where the image is chosen.

What to check

  • Informative images described in the page language
  • Decorative images given empty alt
  • Filenames and the word “image” not used as alt
  • English and Chinese pages not sharing one language’s alt
  • Width and height checked as a separate basic

A practical example

A valve photo has alt="image" and the Chinese page has the same English token. The repair sets the English alt to the valve series and view, and the Chinese alt to the same fact in Chinese. The icon next to it is decorative and gets empty alt. Neither value is the SKU file name.

What this does not claim

Alt text does not guarantee rankings or citations.
