Short answer

Rendering decides whether the first HTML response already contains the text a crawler should read.

Server rendering and static HTML put the product name in the response. Client rendering sends a shell and builds the name after script runs. A crawler that does not execute script, or that executes it later, may see the shell. SEO Health compares those two views on a sample URL when the template depends on JavaScript.

Definition

The diagram of server rendering shows HTML existing before the browser’s extra script work. That is the case worth wanting for the primary content. Static files are the same idea with no per-request build. Client rendering is viable for applications, but the indexable text still needs a path into HTML. This is a technical readiness question, not a promise that any rendering style will rank.

What rendering changes for a crawler

Compare the raw HTML with the rendered result on one commercial URL before editing copy.

If the raw HTML contains the product name, specifications, and the links to related parts, the crawler has a document. If it contains only a root element, the health finding is the shell, not the adjective in the hero. A re-audit after the template ships HTML again should repeat the same comparison. GEO still needs the sentences to be answerable, but answerable sentences that exist only after script are not yet a fetchable document.

What to check

  • Whether view-source contains the product name
  • Whether primary links exist as anchor elements in that HTML
  • A with-JavaScript and without-JavaScript sample of the same URL
  • That the finding is filed as template HTML, not as copy tone
  • A re-audit comparison after the change

A practical example

A spare-parts app renders the fitment table only after a client router runs. View source shows a spinner. The health blueprint says: put the table, or a real server response of the table, in the HTML for the URLs that should be indexed. Adding blog posts about the brand will not fill that shell.

What this does not claim

Choosing a rendering style does not guarantee rankings or citations.
