Robots Rules Can Travel in the HTTP Header

An HTTP header can carry a robots directive for the response, which matters for files that are not HTML.

Short answer

An HTTP header can carry a robots directive for the response, which matters for files that are not HTML.

The photograph shows Tim Berners-Lee speaking, with another person and a laptop nearby. It is a picture of a person associated with the early web, on a page about HTTP headers. It is not a diagram of a header, not a portrait this site uses as an endorsement, and not evidence about any crawler. The rule in this article is the header field itself.

Definition

HTML can use a meta robots element. A PDF or another non-HTML response cannot. An X-Robots-Tag header on that response can say noindex or nofollow for the URL. A header that contradicts the meta element is two rules. Prefer one, and record which one you intend. A header is easy to miss because it does not appear in the body a person reads. A fetch that prints response headers is the check. The photograph does not contain that header.

How a crawl meets this rule

Send robots directives in a response header when the URL is not HTML, and do not contradict the HTML meta.

Fetch the URL and read the status and the headers before you read the body. A noindex header on a public specification is a health finding if the page was meant to be indexed. A noindex header on a private file can be intentional. Say which. Do not add the person’s name from the photograph to the header, and do not treat the photo as a credential.

What to check

  • Non-HTML URLs checked for X-Robots-Tag
  • HTML meta and headers not in conflict
  • Public documents not given an accidental noindex
  • Private files that should stay out are marked on purpose
  • One PDF fetched with headers visible

A practical example

Product PDFs return 200 with no X-Robots-Tag, and the team thought a meta tag in an HTML wrapper applied to the file. It does not. The repair sets the header on the PDF response to the policy they actually want and re-fetches one file. The portrait stays on the source page. It is not part of the header.

What this does not claim

A robots header does not guarantee rankings or citations.
