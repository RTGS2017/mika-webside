Link Rot Is an Internal Path That Now Points Nowhere

Link rot is a link whose target used to exist and now returns an error or a soft empty page.

Short answer

Link rot is a link whose target used to exist and now returns an error or a soft empty page.

Internal rot is an SEO Health defect because the path was part of discovery. External rot is a trust defect when you cited a source that vanished. The not-found picture is the human result of following the link. The status code is what a crawler records. Both belong in the note, plus the source URL that still contains the anchor.

Definition

A redirect that lands on the right replacement is not rot. A redirect to the homepage is a softer form of rot: the click survives and the intent does not. Orphan pages are the opposite shape: the document exists and nothing links to it. Do not merge the two findings into one count. This article will not invent a count.

How the link is a path, not a score

Find internal anchors whose targets error, and retarget, redirect to a true replacement, or remove the anchor.

Checking only the sitemap misses links to URLs that were never listed. A crawl from the homepage and from key hubs finds the anchors. Record the source, the anchor text, the target, and the status. A re-audit after the fix should show that source no longer pointing at the dead target.

What to check

  • Internal targets that return 404, 410, or a soft 404
  • Homepage redirects used where a real replacement exists
  • Source URL, anchor text, target, and status recorded together
  • Orphans kept as a separate finding
  • A re-audit of the source page

A practical example

Three application notes link to /media/old-torque-chart.pdf, which 404s. The chart now lives at a new path. The repair updates the three anchors and adds a redirect from the old PDF URL for people who bookmarked it. Leaving the anchors and only redirecting also works, but updating the anchors keeps the path one hop shorter.

What this does not claim

Repairing broken links does not guarantee rankings or citations.

Where Mika Visibility files this

Mika Visibility treats internal links as SEO Health discovery paths. An orphan has no internal link. A broken link wastes the path. Neither finding is a rank, and neither is a GEO score. Descriptive anchors help a person and a crawler tell pages apart. They do not manufacture authority numbers.

The not-found image is the human side of a dead target. The status code is the other half of the finding.
