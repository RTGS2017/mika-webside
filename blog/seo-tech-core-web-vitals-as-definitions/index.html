Core Web Vitals Are Three Definitions, Not a Site Score

Core Web Vitals are three separate definitions: loading, responsiveness, and visual stability.

Short answer

Core Web Vitals are three separate definitions: loading, responsiveness, and visual stability.

Largest Contentful Paint describes the largest element in the viewport. Interaction to Next Paint describes input delay until the next frame. Cumulative Layout Shift describes unexpected movement. Mika Visibility can talk about each one as SEO Health. It does not add them into an overall score.

Definition

The three definitions answer different questions, so a calm layout does not describe a fast hero image, and a fast hero does not describe a responsive filter. Public range charts exist so people can name bands without measuring a particular company. They are not a measurement of Mika, of a customer, or of this marketing site.

How the definition is used in a health pass

A health pass lists the template, the symptom, and a sample URL for each definition it actually observed.

If a team only has a lab trace, the note should say it is a lab trace. If the only evidence is a screenshot from someone else’s documentation, the note should not pretend it is this site’s field data. SEO Health records what was checked. It does not borrow a number from a chart and call it a result.

What to check

  • Which of the three definitions the note is about
  • Whether the evidence is a lab trace, field description, or only a definition chart
  • The template and one sample URL
  • That the three definitions were not averaged
  • That no overall score was invented

A practical example

A distributor’s category template has a stable layout and a hero that waits on a large render. The health note can mention layout and loading as two lines. Combining them into one experience grade hides which repair comes first. The blueprint can name the hero file as the first repair and leave unanswered application questions on the GEO track.

What this does not claim

Naming the three definitions does not guarantee rankings or citations.

Where Mika Visibility files this

Mika Visibility files this under SEO Health, the track that asks whether the live site is technically ready to be found and understood. SEO Growth remains a separate question about coverage and intent. GEO Health and GEO Growth stay on their own scales. A calm loading or responsiveness note never becomes an automatic growth score, and there is no blended overall score.
