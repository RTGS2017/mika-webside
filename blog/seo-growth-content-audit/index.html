Why it matters

For this light curtain, the question “what mounting height the curtain expects” is the kind of thing a sales engineer repeats. The audit scores length and misses the missing height. That pattern is a growth gap. The navigation can look finished while the decision is still made in email. Public guidance that favors people-first pages is consistent with putting the task on the URL a buyer can open. It is not an invitation to repeat “what mounting height the curtain expects” as a phrase without the constraint.

Label the intent before you choose a URL. Informational intent wants the definition and the condition. Commercial intent wants fit, comparison of constraints, and the document needed before contact. Transactional intent wants the next step the page can honestly offer, such as which configuration to request, not a fake checkout claim. On this note, “what mounting height the curtain expects” is treated as a job for the product page. If the same words also attract a different job, say which job this URL owns and which job it does not. Mixed intent is a reason to be explicit. It is not a reason to write three slogans in one hero.

A practical example

Take a light curtain product page. A buyer asks what mounting height the curtain expects. The audit scores length and misses the missing height. The useful edit is small and specific. State the condition, state the exclusion, and name the document that sits next to the claim. For each priority question, mark answered, partial, or uncovered on a live URL. Do not publish a city-and-product template that repeats the same paragraph. Do not invent a customer, a score, or a result to make the example look like a case study. The example is a teaching shape, not a report of someone’s numbers.

Content depth

Depth here is not a word count. A long product page that never answers “what mounting height the curtain expects” is still thin. A short product page that states the fit and the limit can be complete when the job is small. Depth for this topic means the use case, the constraint, and the proof are on the same URL. If the only copy of the fact is inside an image, a slide, or a chat log, the HTML page is still partial. Search and readers both need the sentence in text. How an unanswered topic gets found

A site gets found for a topic it does not yet answer only after the answer exists on a URL that other pages point to. Create or edit the product page so “what mounting height the curtain expects” is answered in the first screen. Then add a descriptive internal link from the page where the question starts — often the product or category URL — using words a buyer would recognize, not “click here”. Keep a single canonical URL for that answer. A second thin page splits the path. An XML sitemap can list the URL after it is real; the sitemap does not invent the answer. Orphan pages, with no internal links, stay hard to discover even when the paragraph is good. The next re-audit checks three things: the answer is on the owner, the internal link resolves, and no near-duplicate contradicts it. That is how an uncovered light curtain question becomes a page someone can reach. It does not promise a position in search results.
