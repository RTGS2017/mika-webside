Short answer

A 410 response means this URL was a document and that document has been removed on purpose. Use it when nothing should replace the subject. Do not use it for a page that still exists at a new address.

Definition

A 404 can mean a typo, a temporary outage, or a real gap. A 410 is the stronger statement that the URL is finished. Sending a dead product URL to the homepage keeps a crawl path and drops the subject. If a successor document exists, 301 to that document instead. Internal links should stop pointing at the gone URL. The sitemap should drop it.

What belongs on the page

List URLs whose subject you retired. For each, pick successor or gone. Fetch the status after the change. A 200 page that only says “not found” is a soft problem of a different kind. A 410 should not return a long indexable article about an unrelated topic.

What to check

  • Use 410 only when no successor document exists.
  • Remove internal links to that URL.
  • Remove it from the sitemap.
  • Do not answer 410 with a homepage redirect.

A practical example

A discontinued fitting URL 301s to the site homepage, which never names the fitting. The repair returns 410, removes the internal links and the sitemap entry, and leaves any real successor on its own URL. No demand number is claimed.

What this does not claim

Returning 410 does not guarantee rankings for the pages you keep, and it is not an AI-citation tactic.
