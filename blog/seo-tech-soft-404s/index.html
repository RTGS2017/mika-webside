A Soft 404 Says the Page Is Fine and Also That Nothing Is There

A soft 404 is a URL that returns success while the body says the content is missing.

Short answer

A soft 404 is a URL that returns success while the body says the content is missing.

The status and the words disagree. A crawler that trusts the status may keep the URL as a thin document. A person sees an empty state. SEO Health wants the status to tell the truth: 404 or 410 when the document is gone, or a real document when the status is 200.

Definition

Search tools sometimes label this pattern in their own reports. This article does not show such a report and does not invent a count of soft 404s. The check is local: fetch the sample URL, read the status, read the body. Empty search results that return 200 can be the same pattern if the URL is linked as if it were a document.

How this affects the indexable URL

Fetch the URL and require the status and the body to tell the same story.

A useful empty state for a filter can stay 200 if it is not a URL you ask crawlers to index and you do not link it as a landing document. The defect is presenting that empty state at a sitemap URL or at an internal link that looks like a product. Canonical tags do not repair a 200 that should have been a 404.

What to check

  • HTTP status on URLs whose body says nothing is there
  • Those URLs removed from the sitemap when they are not documents
  • Internal links that treat empty states as products
  • Filter views that are allowed to be 200 only when they are not index targets
  • One sample URL with both status and heading recorded

A practical example

/products/old-series returns 200, the heading “no products found,” and the URL is still in the XML sitemap. The repair is a 410, removal from the sitemap, and removal of internal links. The heading can remain for anyone who still has the old address, under the honest status.

What this does not claim

Fixing a soft 404 does not guarantee rankings or citations.
