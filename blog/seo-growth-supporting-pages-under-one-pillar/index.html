Direct answer

A pillar page introduces a subject. Each supporting page should answer a different question under that subject and link back. SEO Growth is the set of questions still missing. A cluster of near-duplicates is not a pillar.

Why it matters

Topic coverage means depth without manufacturing near-duplicate pages. The pillar can name the product family and link the questions. A supporting URL that only swaps a modifier into the pillar paragraph collides with it. Give the support page its own fact, or do not publish it. Internal links both ways use descriptive anchors.

What to check

List the questions the family must answer. Assign each uncovered question to an existing URL or to one new URL with a brief. On the pillar, link those URLs by the question text. Remove supports that do not add a fact.

  • Each support URL answers a different question.
  • The pillar links them with those questions as anchors.
  • Support pages link back to the pillar or the product.
  • Delete supports that only repeat the pillar.

A practical example

A “pump pillar” links six posts that repeat the same head range with different adjectives. The repair keeps one page for the range and adds a support page only for the separate question of suction conditions, with its own limit. No topic-authority score is claimed.

Content depth

The cluster is deep when the questions are distinct and answered. Counting URLs under a hub is not depth.

How an unanswered topic gets found

A support page with no link from the pillar is an orphan even if it is good. A pillar with no links is a dead end. Re-audit the hub and one support URL together.

A pillar is a map of questions, not a folder of copies. Mika Visibility files this on the SEO Growth track: coverage, intent depth, and markets that are still open. It is not an SEO Health score and it is not GEO. Page count is not growth. There is no blended overall score.

What this does not claim

A tidy cluster does not guarantee topical rankings or AI citations. Mika does not publish an authority score.
