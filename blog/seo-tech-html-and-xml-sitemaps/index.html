An HTML Sitemap and an XML Sitemap Do Different Jobs

An XML sitemap lists URLs you offer for crawling. An HTML sitemap is a page of ordinary links.

Short answer

An XML sitemap lists URLs you offer for crawling. An HTML sitemap is a page of ordinary links.

The tree diagram shows discovery by links, which is the HTML idea. The XML file is a manifest: loc, and optionally lastmod. A crawler may ignore a URL in the manifest, and it may fetch a URL that is not in the manifest if a link points there. SEO Health looks for disagreements between the list, the canonical URLs, and the links.

Definition

An indexation mismatch is that disagreement: a sitemap URL that redirects, a sitemap URL that is noindexed, or an important canonical URL missing from the sitemap. The sitemap protocol also documents size limits for a single file. Those limits are specification constraints, not a score. Hitting a limit means split the file. It does not mean the site grew in a useful sense.

How a crawl meets this rule

Compare sitemap URLs with canonical, indexable URLs and with URLs that links actually discover.

Lastmod is useful only when it changes because the document changed, not because a script rewrites today’s date on every build. A fake fresh date is a health defect in the feed. HTML sitemaps help when they are real anchors to important pages. A page that exists only in the XML file and has no internal link is still weakly connected. Orphan discovery stays a link question.

What to check

  • Sitemap URLs that redirect, 404, or carry noindex
  • Canonical URLs missing from the sitemap
  • lastmod values that change without a document change
  • Important pages that have no internal link even if they are listed
  • One mismatched URL written into the note

A practical example

The XML sitemap lists /products/legacy-valve, which 301s to /products/valve, and omits the current canonical. The HTML footer links to the current URL. The mismatch is the sitemap row. Updating lastmod on the redirected URL would not fix it. The repair is to list the canonical URL and drop the retired one.

What this does not claim

A sitemap does not guarantee indexation, rankings, or citations.
