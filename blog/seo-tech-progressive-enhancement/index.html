HTML Is the Base of the Page, and Script Is the Top

Short answer

Progressive enhancement puts the document’s text in HTML first, then adds presentation and behavior.

The pyramid in the figure is wide at the HTML base, narrower for CSS, and a small tip for JavaScript. That picture is a design order, not a score. SEO Health uses it as a test: if the tip is removed, does the fetch still contain the subject, the title, and the links? If the answer is no, the page is a script, not a document with an enhancement.

Definition

CSS can be absent and the words can still be read. Script can fail to run and the anchors can still be followed. An enhancement that is the only copy of the price, the specification, or the next URL is not an enhancement. It is the document, stored in the wrong layer. The pyramid does not say that JavaScript is forbidden. It says the base has to hold the meaning.

What rendering changes for a crawler

Keep the subject, the primary text, and the crawl paths in the HTML a fetch returns.

A menu that appears only after a script builds it is above the base. Give the same destinations real anchors in the HTML, and let the script restyle them if you want. Compare one URL with script disabled or with a plain fetch. The pyramid’s colors are not a grade. A page can be orange, blue, and yellow in the diagram and still hide its only H1 in the yellow tip.

What to check

  • A fetch that contains the subject and the links
  • Script that restyles those links instead of creating the only copy
  • A comparison with script not required for the text
  • The H1 present in the HTML
  • One catalog URL fetched as HTML

A practical example

A catalog card’s name and link exist only after a component renders. The server response is a shell. The repair renders the name and the anchor in the HTML and keeps the filter behavior as script. A second fetch without running script shows the card. The pyramid stays a picture of the order, not a certificate.

What this does not claim

A progressive base does not guarantee rankings or citations.

Where Mika Visibility files this

Mika Visibility treats rendering as an SEO Health question: can the important HTML be fetched and compared with and without JavaScript when the template depends on it. That comparison is not a GEO audit and not a market-coverage plan. Findings stay attached to sample URLs. A re-audit after the template change is how the team checks the repair.

The pyramid is an order of layers. The audit reads the HTML layer.
