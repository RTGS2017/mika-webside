Direct answer

An informational page owns a definition when that URL states what the subject is and the condition that limits the statement. SEO Growth asks whether this job is still uncovered. It is not a promise of a blue link.

Why it matters

Informational intent wants the meaning and the boundary, not a checkout and not a slogan. If three URLs repeat “what it is” and none states the boundary, the coverage is still partial. Create a new URL only when the definition is a different job from the page that already exists. Otherwise edit the owner.

What to check

Write the question in plain language. Name the owner URL. Put the definition in the first screen, in HTML text. Mark the question answered, partial, or uncovered. Link to it from the page where a buyer first meets the term, with words the buyer would use.

  • One URL owns the definition.
  • The first screen states the subject and the condition.
  • Other pages link to that URL instead of repeating a slogan.
  • The question is marked answered, partial, or uncovered.

A practical example

A buyer asks what a weep hole does on a cladding panel. Three pages say the system “breathes,” and none says when the hole is required. The useful edit adds that condition to the one panel page and points the other two at it. This is a teaching shape, not a traffic case.

Content depth

Depth is the condition and the exclusion, not a longer adjective. A short definition that states both can be complete. A long page that never answers is still thin.

How an unanswered topic gets found

The page is found when other URLs link to the owner with a descriptive anchor and the sitemap lists the URL only after the answer exists. An orphan definition stays hard to discover. Re-audit the live HTML. That does not promise a position.
