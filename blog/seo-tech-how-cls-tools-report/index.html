Short answer

A layout-shift tool lists events and contributions. It does not hand you a rank.

Calculators and lab audits are interfaces for exploring a definition. A screenshot of a calculator is not field data, and it is not a score this page assigns to anyone. SEO Health can say which element a lab audit blamed on a sample URL. It cannot paste the calculator into a report and call the picture a measurement.

Definition

Lab output and field description answer different questions. A lab run is one scripted load. Field data, when a team truly has it, summarizes real visits. This article does not have either for a named company, so it will not invent one. The useful habit is to label the source of the observation before anyone debates a repair.

How the definition is used in a health pass

Label every layout note as lab, field, or definition-only, and never treat a calculator screenshot as a site result.

When a lab audit points at an image without dimensions, the repair is the image slot on that template. When the only artifact is a picture of a scoring UI, there is no element to fix until someone reproduces the page. SEO Health stays with reproducible observations and sample URLs. A growth conversation about missing topics can wait.

What to check

  • Whether the note says lab, field, or illustration
  • The element a real audit named, if one was run
  • No cropped calculator treated as a company result
  • A sample URL when a template was actually loaded
  • Separation from SEO Growth topic gaps

A practical example

A slide deck includes a calculator cropped so a number looks like “our CLS.” The number was never measured on the company’s templates. The honest replacement is a lab note: the category hero has no width or height, sample URL attached, no overall grade. Mika does not want the cropped picture in the audit.

What this does not claim

Tool screenshots do not guarantee rankings or citations, and this page does not guarantee a layout result.
