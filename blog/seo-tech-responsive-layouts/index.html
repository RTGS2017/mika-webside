A Responsive Layout Reflows One Document

A responsive layout is one document that reflows when the viewport gets narrower.

Short answer

A responsive layout is one document that reflows when the viewport gets narrower.

The screenshot is a wide desktop view of an encyclopedia article: a sidebar and a broad column. It shows one width. It does not show the narrow reflow, and it is not a layout this site is copying. SEO Health asks whether your document remains one URL, with the same text, when the window changes. A separate mobile URL that repeats the page is a duplicate, not a responsive layout.

Definition

Reflow is CSS. The viewport meta lets a phone use its own width as the layout width. Together they are a page basic. They do not add a second document, and they do not prove that the text exists. If the narrow layout hides the H1 or the specification behind a control that has no HTML equivalent, the fetch may still contain them, but the person cannot use them. Check both the source and a narrow window.

What belongs in the page basics

Keep one URL and let CSS reflow it, including at a narrow width.

Do not publish a second host or a /m/ path that copies the document. Do not remove the primary text at the narrow breakpoint. Open one product URL wide, as in the kind of desktop view the screenshot shows, and then narrow. The title, the H1, and the specification should still be the same words. Horizontal scrolling on the whole page is a failed reflow, not a style.

What to check

  • One canonical URL for the document
  • No copied mobile path
  • The same H1 at a narrow width
  • The viewport meta present so the phone uses device width
  • One product URL checked wide and narrow

A practical example

The site serves the same valve page at /m/valve with a canonical that points at itself, and the desktop URL also points at itself. Two documents exist. The repair keeps the desktop URL, redirects the /m/ path, and fixes the breakpoint that had chopped the specification off. The encyclopedia screenshot remains someone else’s wide view.

What this does not claim

A responsive layout does not guarantee rankings or citations.
