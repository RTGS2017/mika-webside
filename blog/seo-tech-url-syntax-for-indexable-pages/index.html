A URL Has Parts, and the Indexable One Should Be Stable

A URL is a scheme, a host, a path, an optional query, and an optional fragment.

Short answer

A URL is a scheme, a host, a path, an optional query, and an optional fragment.

The fragment is for the browser and is not sent to the server as part of the fetch. A query selects a variant. The path is the usual identity of a document. SEO Health picks one of those strings as the canonical URL and uses it consistently in links, the sitemap, and the canonical element.

Definition

The syntax diagram is a labeling aid. It does not say which spelling a company chose. That choice is local: one host, one scheme, one path form. Everything else should redirect or stay out of the indexable set. A canonical element that points at a different spelling than the sitemap recreates the split the redirects were meant to close.

How this affects the indexable URL

Choose one scheme, one host, and one path form, and keep fragments out of indexable identities.

http and https, www and the bare host, and a trailing slash versus none are three ways to spell two documents or one. The health rule is to redirect the unused spellings to the canonical URL and to reference only that URL internally. A fragment such as #specs can still exist for people. It should not be the URL you list in a sitemap.

What to check

  • One scheme and one host chosen as canonical
  • Trailing-slash consistency with redirects for the other form
  • Fragments not used as sitemap identities
  • Internal links using the chosen spelling
  • A sample URL showing the unused spelling redirect

A practical example

Product links sometimes point at http://www.example.com/pumps#curve and sometimes at https://example.com/pumps/. Both hosts respond. The canonical choice is the https bare host without the fragment. Redirects cover the other spellings. The sitemap lists only the chosen URL. The curve section can remain an in-page heading.

What this does not claim

A stable URL spelling does not guarantee rankings or citations.
