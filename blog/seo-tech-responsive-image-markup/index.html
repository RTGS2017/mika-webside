Responsive Image Markup Sends a File That Matches the Slot

Short answer

Responsive image markup lets the browser choose a file that fits the slot it will paint.

srcset lists candidate files. sizes tells the browser how wide the slot is in the layout. Art direction, a different crop for a narrow screen, is a further choice using picture. None of that markup writes the alt text, and none of it reserves the box unless width and height or a ratio are also set.

Definition

Sending a 2000-pixel product photo into a 400-pixel card wastes transfer. Sending a tiny file into a full-bleed hero looks soft. The health check is whether the markup matches the slot on that template. The art-direction figure shows crops, which is a layout choice. It is not a performance score.

What belongs in the page basics

Match candidate files to the real slot, and keep alt text plus a reserved box on the same image.

A template that uses one enormous file for every breakpoint is a health note about bytes. A template that swaps crops but drops the alt attribute is a health note about the text alternative. They can both be true. SEO Health lists them separately. The image content, what the photo depicts, still belongs in alt in the page language.

What to check

  • srcset candidates that match thumbnail versus hero slots
  • sizes that describe the layout slot
  • Alt text still present in the page language
  • Width and height or a ratio so the box is reserved
  • One product template URL checked at two widths

A practical example

A product template serves the original camera file in a sidebar thumbnail and also uses that URL as the hero without a larger candidate. The thumbnail wastes bytes and the hero is soft. The markup should offer a small file for the sidebar and a larger one for the hero, with alt text that names the product, and width and height so the sidebar does not jump.

What this does not claim

Responsive candidates do not guarantee rankings or citations. This does not guarantee a richer image result either.
