A Content Security Policy Can Block Your Own Page’s Assets

Short answer

A content security policy tells the browser which sources may supply scripts, styles, images, and other assets.

The diagram maps features to directives: stylesheets toward style-src, scripts toward script-src, images toward img-src, fonts toward font-src, and others, with arrows toward a web server. The caption on the source figure ties the drawing to an older draft. This article uses it as a map of the idea, not as a configuration to paste, and not as a current score.

Definition

A policy is a response header or a meta element. If it blocks the stylesheet on your own host, the fetched HTML is unstyled. If it blocks the script that only enhances a menu, the HTML base should still work. If it blocks the only copy of the product text because that text was injected by a blocked script, the document fails. CSP is not robots.txt. A crawler can fetch the HTML while a browser refuses the assets. Check both.

What rendering changes for a crawler

Allow the assets your document needs, and keep the primary text in HTML if a policy might block script.

Read the browser’s refusal for one product URL after a policy change, and name the directive. A report of a blocked third-party host is not the same as a blocked first-party stylesheet. Do not loosen the policy to allow every host because a diagram shows many arrows. Add the host that serves the file you intend. The drawing’s server cylinder is not your origin unless you check.

What to check

  • First-party CSS and images allowed if the page uses them
  • Primary text still in the HTML
  • A blocked asset named by its directive
  • The policy not copied from the diagram
  • One product URL loaded with the console or the network record checked

A practical example

A new policy allows scripts from one host and omits the host that serves the product CSS. The page is unstyled and the layout collapses, while the HTML fetch still contains the H1. The repair adds that host to style-src and confirms the CSS request. The diagram is not pasted in as the header. The H1 was never the thing that was blocked.

What this does not claim

A content security policy does not guarantee rankings or citations.
