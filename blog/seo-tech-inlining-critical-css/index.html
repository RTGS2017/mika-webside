Inlined Critical CSS Is Only the CSS for the First Screen

Short answer

Critical CSS is the subset of rules needed to paint the first viewport, sometimes inlined in the head.

The rest of the stylesheet can load without blocking that first paint. If you inline every rule, the HTML gets heavy and the “critical” subset was never chosen. The overflowing-screen figure is a picture of layout that does not fit, which is one reason people extract above-the-fold rules. It is not a measurement.

Definition

Extraction can be done by hand for a stable template or by a build step that is reviewed. An unreviewed extractor can inline rules for a state the page is not in, or miss the rules that prevent a layout jump. SEO Health treats the result as markup to inspect on a sample URL: is the first screen styled, and is the HTML not carrying the whole design system.

What rendering changes for a crawler

Inline only the first-screen rules, and confirm on a sample URL that the full sheet is not also duplicated in the head.

A layout jump after the full sheet arrives means the critical subset was incomplete. That is a CLS-shaped defect caused by the CSS split, and it should be noted as such. The repair is to include the missing rules in the subset, not to abandon the idea and block on the entire file again without looking.

What to check

  • The inlined rules match the template’s first screen
  • The full sheet is not copied into the head as well
  • No layout jump when the full sheet arrives
  • A product URL and a home URL checked separately
  • Extractor output reviewed rather than trusted blindly

A practical example

A build inlines the homepage hero rules into every product page, and the product title uses different rules that arrive later, so the title jumps. The health note says the subset follows the homepage, not the product template. Each template needs its own first-screen subset or none.

What this does not claim

Inlining a subset does not guarantee rankings or citations.
