What Usually Moves a Layout After First Paint

Layout shift is unexpected movement of content that was already visible.

Short answer

Layout shift is unexpected movement of content that was already visible.

The common causes on a B2B template are an image that arrives without a reserved box, a web font that changes line breaks, and a banner inserted above the title. A click the visitor chose, such as opening a specification accordion, is a different event from a widget that appears on its own.

Definition

The performance panel can list shift records next to the elements that moved. That view is a way to see the event. It is not a measurement of Mika, of a customer, or of this marketing site. SEO Health uses it to name the template defect. It does not convert the trace into a rank.

How the definition is used in a health pass

Keep a sample URL and the element that moved, and do not treat an expected click as the same defect as an injected bar.

Reserving width and height, or an aspect-ratio box, stops the hero from pushing the datasheet link down when the file arrives. A font that swaps can be limited to a fallback with similar metrics, or loaded in a way that does not reflow the heading. A consent or chat region needs a stable slot if it must be on the page. The repair is positional. Rewriting the product adjective does not hold the layout still.

What to check

  • Images and iframes without a reserved box
  • Fonts that change wrapping after first paint
  • Bars inserted above content that was already visible
  • Whether the movement followed a visitor’s own click
  • A sample URL stored with the element name

A practical example

A fittings page paints the name, then a promotional strip is injected by a tag manager and the “download CAD” link jumps. The health finding is the strip’s insertion point. The CAD file’s usefulness is a content question for another track. Until the strip has a slot, adding more downloads will not stop the jump.

What this does not claim

Stopping unexpected movement does not guarantee rankings or citations.
