UTF-8 Is the Encoding to Declare and to Send

Short answer

UTF-8 is a character encoding that can hold Chinese and Latin text in the same HTML file.

The chart lists UTF-8 and several older encodings as stacked bars across years. The blue series is UTF-8, and the drawing shows it as the large series in the later years. This article does not read any bar as a metric for Mika, for a customer, or for the web as a whole. The health rule is local: declare UTF-8 and send UTF-8.

Definition

A bilingual page that is saved as GB2312 or Windows-1252 while the template says UTF-8 will break one of the languages. The HTTP charset and the meta charset should agree with the file. A byte-order mark accidentally left at the start can shove the doctype down and confuse parsers. Editors and build tools must save the template as UTF-8 without adding a second conversion. The chart’s legend is a list of names, not a menu of encodings to support on purpose.

What belongs in the page basics

Save HTML as UTF-8 and declare UTF-8 in the response.

Check the Content-Type charset, the meta charset, and the actual bytes of a page that contains both a Chinese sentence and an English model name. If any one of the three disagrees, fix the pipeline rather than adding a second meta. Do not cite the chart’s bars as a reason the declaration can be skipped. A popular encoding that you did not send is still the wrong encoding.

What to check

  • The file saved as UTF-8
  • The HTTP charset and the meta both say UTF-8
  • Chinese and Latin strings intact in the fetch
  • No extra recode in the build
  • One bilingual product URL fetched

A practical example

The Chinese product page displays the family name correctly in an editor and as replacement characters after deploy, because the build recoded the file and left the meta as UTF-8. The repair stops the recode. A fetch shows the family name as the same characters the editor saved. No percentage is copied from the chart.

What this does not claim

Sending UTF-8 does not guarantee rankings or citations.
