An SVG Diagram Stays Sharp Because It Is Drawn, Not Sampled

SVG is a drawing of shapes, so a diagram can scale without the blocky edges a stretched raster shows.

Short answer

SVG is a drawing of shapes, so a diagram can scale without the blocky edges a stretched raster shows.

The figure places the same mark twice. The left copy is a raster and shows square edges. The right copy is SVG and stays smooth. That is the technical difference. It is not a ranking difference, and it does not mean every photograph should become SVG. Photos remain rasters. Diagrams, simple marks, and icons that must stay sharp are the usual SVG cases.

Definition

An informative diagram needs a name a fetch can read. Inline SVG can include a title element, and an img that points at an SVG file needs alt, just as a PNG does. A diagram that contains the only copy of a specification, with no HTML table beside it, hides that specification from a text fetch. Use SVG for the drawing and HTML for the sentences and numbers. Decorative SVGs can have empty alt.

What belongs in the page basics

Use SVG for sharp diagrams, and keep the facts in HTML with a text alternative on the drawing.

Set width and height so the SVG does not shift the layout when it loads. Do not build the product name out of paths and leave the H1 empty. If the SVG is inline and huge, it becomes part of the document weight. A file referenced by img can be cached on its own. The side-by-side mark in the figure is a comparison of edges, not a logo to paste.

What to check

  • Diagrams that need sharp edges considered for SVG
  • Alt or a title on informative SVG
  • Values also present in HTML
  • Width and height set
  • One diagram URL or inline SVG checked beside its table

A practical example

A pressure curve exists only as a PNG that blurs, and the values are not in the HTML. The repair redraws the curve as SVG with alt that states what the curve is, and puts the values in a table. The letterform in the figure is not reused. The table is what a fetch reads.

What this does not claim
