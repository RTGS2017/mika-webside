A CSS Class Changes Appearance. The Element States the Role

A CSS class sets how an element looks. The element type is what tells a parser the role.

Short answer

A CSS class sets how an element looks. The element type is what tells a parser the role.

The stylesheet in the figure defines classes whose names are colors, alignments, and sizes: red, green, center, giant, and so on. Those rules change paint and type size. They do not create a heading. SEO Health still looks for an H1 on the subject. A div with a class called giantTitle is a large div. The pixel sizes in the screenshot are an example of presentation rules, not sizes this site recommends.

Definition

You can keep the classes for color if the design needs them. Put them on a real heading when the line is a heading, and on a paragraph when it is a paragraph. A class name that says “title” is a hint to a person reading the CSS. It is not the outline. Avoid a rule that sets type so small that the words effectively disappear. The screenshot includes very small sizes as part of its example. That is not a technique to copy onto a product name.

What belongs in the page basics

Use the element for the role, and use the class only for appearance.

One H1 that is an h1 element. Navigation that is a nav or a list of anchors, not a set of colored divs. Read the outline from the HTML, then look at the stylesheet only to see whether it hides that outline. The class names in the figure can stay on the source page as an illustration of presentation. They are not an information architecture.

What to check

  • The subject written as an h1 element
  • Classes used for color or alignment, not as a substitute outline
  • Navigation as anchors, not only colored divs
  • No rule that shrinks the product name out of view
  • One product URL’s outline read from HTML

A practical example

The product name is a div with class giantTitle and the slogan is the only h1, styled smaller. The repair makes the product name the h1 and leaves a color class on it if the design still wants the color. The fetched outline matches the page a person sees. None of the screenshot’s font sizes are copied.
