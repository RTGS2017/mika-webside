First Contentful Paint Is the First Content, Not the Largest

Short answer

First Contentful Paint marks when the first text or image is painted.

That moment can be a line of navigation text long before the product photo, which is often the largest element. The two definitions answer different questions. A page can paint something quickly and still leave the main subject late. SEO Health should not collapse them into one speed word.

Definition

First Contentful Paint is useful when the document is blocked by a stylesheet or a script in the head, because nothing contentful can paint until that block clears. It does not describe layout movement, and it does not describe input delay. A public timeline image is an illustration of the idea. It is not a measurement of Mika, of a customer, or of this marketing site.

How the definition is used in a health pass

Record whether anything contentful paints before the main subject, and what blocked that first paint.

Render-blocking CSS in the head delays the first paint even if the hero image is well compressed. A late hero is an LCP question. An empty first screen is closer to this definition. Teams that only watch the largest element can miss a head script that holds the whole document. The health note can carry both lines when both were observed, still as separate lines.

What to check

  • Stylesheets or scripts in the head that block the first paint
  • Whether the first paint is only chrome, not the subject
  • That this mark is not used as a substitute for the largest element
  • A sample URL where the first paint was observed
  • Separate notes when both first paint and largest paint are late

A practical example

A documentation template inlines no CSS and waits on a large site-wide stylesheet before the title appears. The product photo is a later problem. The first repair is the blocking sheet, recorded against one article URL. Translating the article does not unblock the stylesheet.

What this does not claim

An earlier first paint does not guarantee rankings or citations.
