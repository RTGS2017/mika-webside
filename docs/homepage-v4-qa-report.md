# Homepage V4 验收记录

1. 架构：静态站，发布根是仓库根，不是 `dist/`。英文在 `/`，中文在 `/zh/`。
2. 发布页已删除 Hero 前景卡片和旧的 Website 方框。概念留在索引树节点和后续章节正文里。
3. 索引树由 SVG 从根节点依次生长。搜索蓝、答案紫。窄屏节点更少。离开首屏时树向上收缩。
4. 动效仍是描边、信号、扫描、展开、构建，没有 WebGL。
5. 桌面滚轮一次一章。高章节可先读完。吸附在缓动时暂停。章节轨在左侧。
6. 手机隐藏章节轨，不接管滚轮，索引树用短链。
7. 中文首页界面词已替换。`python tools/zh_content_audit.py` 扫描 `zh/index.html`。
8. SEO 正文仍在 DOM。canonical / hreflang 未改。Hero SVG 是装饰层。
9. 没有 npm build。发布就是推送 `main`。
10. 方法章节补进了左侧章节轨，所以轨上是 14 项。知识文章正文没有逐篇重写。改动还在本地，未推送。
