What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state the values in HTML, even if a scan is also offered as a download. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: whether the fact exists as text or only as a scanned picture? One short passage should be quotable on its own.
