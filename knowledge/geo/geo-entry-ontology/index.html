How this shows up on a website

Answer systems do not receive a private briefing from sales. They read sentences, names, tables, and links that the HTML actually contains. When the text never settles what category the product belongs to, and what it does not belong to, the summary has to guess the class and the exclusion. That guess is a failure of the page, even when the site is technically reachable.

Category language is commercial only when the page can honestly support it. Do not place a product in a class because the class has more searches. Place it in the class your specification supports, and say what the class excludes. That is how commercial intent stays tied to a real page instead of a keyword list.

Question coverage still has three honest states: answered, partial, and uncovered. A page that names the topic but never answers what category the product belongs to, and what it does not belong to is partial at best. A site that never asks the question at all is uncovered. GEO Growth is the place to record that gap. GEO Health is the place to record whether the pages you already have can support an answer. Neither scale is an overall blended score.

What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state the class, a parent class if you have one, and one exclusion. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: what category the product belongs to, and what it does not belong to? One short passage should be quotable on its own. If the passage still leaves the class and the exclusion, mark the coverage partial and add the missing constraint, range, or exclusion instead of another adjective.

Put evidence next to the claim

The evidence for this page is the sentence on the product page, repeated in the glossary if the class name is specialized. Link it with anchor text that names the destination, and make sure the target URL returns the document you mean. A claim with no openable support is not citation-ready, even if the sentence sounds confident.

Repeat the same fact in both languages

English at the site root and Chinese under /zh/ should keep the same company name, product name, specification, and application. Translation may change word order. It should not invent a second an ontology or a second operating range. Hreflang marks the alternates. It does not guess which language an answer product will prefer.
