What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state the limits and exclusions in the same passage as the benefit. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: which details a draft might invent because the page is silent? One short passage should be quotable on its own. If the passage still leaves the exclusion that would have blocked a guessed detail, mark the coverage partial and add the missing constraint, range, or exclusion instead of another adjective.

Put evidence next to the claim

The evidence for this page is the specification row that states the limit. Link it with anchor text that names the destination, and make sure the target URL returns the document you mean. A claim with no openable support is not citation-ready, even if the sentence sounds confident.

Repeat the same fact in both languages

English at the site root and Chinese under /zh/ should keep the same company name, product name, specification, and application. Translation may change word order. It should not invent a second a hallucinated detail or a second operating range. Hreflang marks the alternates. It does not guess which language an answer product will prefer.

A practical example

A page that says chemical duty and never names the fluids leaves room for an invented fluid list. Name the fluids you support and say others are not stated.
