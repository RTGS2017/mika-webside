How this shows up on a website

Answer systems do not receive a private briefing from sales. They read sentences, names, tables, and links that the HTML actually contains. When the text never settles whether the answer is in a heading and a paragraph, not only in a styled div, the summary has to guess a real heading that states the question. That guess is a failure of the page, even when the site is technically reachable.

What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state the question as a heading and the answer as the next paragraph or list. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: whether the answer is in a heading and a paragraph, not only in a styled div? One short passage should be quotable on its own. If the passage still leaves a real heading that states the question, mark the coverage partial and add the missing constraint, range, or exclusion instead of another adjective.

Put evidence next to the claim

The evidence for this page is the heading text itself, because it is part of the document outline. Link it with anchor text that names the destination, and make sure the target URL returns the document you mean. A claim with no openable support is not citation-ready, even if the sentence sounds confident.

Repeat the same fact in both languages

English at the site root and Chinese under /zh/ should keep the same company name, product name, specification, and application. Translation may change word order. It should not invent a second semantic html or a second operating range. Hreflang marks the alternates. It does not guess which language an answer product will prefer.

A practical example

A div that looks like a heading but is not an h2 is easy to miss in an outline. Use a real heading for the question Which fluid is supported and a list for the fluids. The contrast used across Mika’s teaching material is the same kind of contrast: a page of slogans versus a page that names the company, the product family, the application, and a constraint, with a datasheet beside the claim. That scene is illustrative. It is not a customer story, and it is not a measured result.
