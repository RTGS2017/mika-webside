Definition

A specification table is a grid whose headers are fields and whose cells are values. Empty headers are not evidence. How this shows up on a website

Answer systems do not receive a private briefing from sales. They read sentences, names, tables, and links that the HTML actually contains. When the text never settles which field, unit, and value the table commits to, the summary has to guess machine-readable cells for the values. That guess is a failure of the page, even when the site is technically reachable.

The practical move is small and specific: column names, units, and one row per model you actually sell. Put that passage where a buyer lands, not only in a slogan line or a title attribute. Tables are where units go wrong. State the unit in the header, not only in a footnote three screens away. Keep the same unit on the Chinese page or show the conversion in the cell. A table that mixes bar and psi without labels is two facts pretending to be one.

Question coverage still has three honest states: answered, partial, and uncovered. A page that names the topic but never answers which field, unit, and value the table commits to is partial at best. What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state column names, units, and one row per model you actually sell. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: which field, unit, and value the table commits to? One short passage should be quotable on its own. If the passage still leaves machine-readable cells for the values, mark the coverage partial and add the missing constraint, range, or exclusion instead of another adjective.

Put evidence next to the claim

The evidence for this page is the table on the page, not a picture of a table with no text alternative. Link it with anchor text that names the destination, and make sure the target URL returns the document you mean. A claim with no openable support is not citation-ready, even if the sentence sounds confident.

Repeat the same fact in both languages

English at the site root and Chinese under /zh/ should keep the same company name, product name, specification, and application. Translation may change word order. It should not invent a second a specification table or a second operating range. Hreflang marks the alternates. It does not guess which language an answer product will prefer.

A practical example

A JPEG of a spreadsheet cannot be quoted as text. An HTML table with model, pressure, unit, and revision can. If you must use an image, repeat the values in HTML. The contrast used across Mika’s teaching material is the same kind of contrast: a page of slogans versus a page that names the company, the product family, the application, and a constraint, with a datasheet beside the claim. That scene is illustrative. It is not a customer story, and it is not a measured result.
