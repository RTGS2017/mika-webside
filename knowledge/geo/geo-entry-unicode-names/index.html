What to check

Say the name in the body

Put the concrete name in a sentence a stranger can read without opening a menu. The first screen should state one canonical spelling, pasted from the specification, not retyped from memory. A heading that only says “solutions” does not identify the entity, and a model number buried in a download does not help a summary that never sees the sentence.

Answer the question in one passage

The question to answer in plain language is: whether the name uses the characters you intend? One short passage should be quotable on its own. If the passage still leaves a single canonical spelling, mark the coverage partial and add the missing constraint, range, or exclusion instead of another adjective.

Put evidence next to the claim

The evidence for this page is a comparison of the code points in the title and in the datasheet. Link it with anchor text that names the destination, and make sure the target URL returns the document you mean. A claim with no openable support is not citation-ready, even if the sentence sounds confident.

Repeat the same fact in both languages

English at the site root and Chinese under /zh/ should keep the same company name, product name, specification, and application. Translation may change word order. It should not invent a second unicode lookalikes or a second operating range. Hreflang marks the alternates. It does not guess which language an answer product will prefer.

A practical example

A Latin letter replaced by a similar letter from another script makes a second string. Searches and summaries can treat it as a different product. Normalize the name.
